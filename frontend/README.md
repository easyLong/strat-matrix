界面颜色已按客户《1.5 颜色 – Color》逐项对齐：品牌紫 `#7860FE`、辅助紫 `#4E1AA5`及成功/警告/失败、四级文字透明度、分割线与背景。见[颜色对应表与验收说明](COLOR_SPEC.md)。

已按驻场要求适配：`vue: ^2.6.14`（lock锁定2.6.14）、`vuex: 3.6.0`、`axios: 1.8.2`、`element-ui: 2.15.13`。Vue Router使用3.6.5，编译器与Vue统一为2.6.14；通过`npm ci`安装锁定依赖。宿主接入与验收边界见[Vue2迁入说明](VUE2_INTEGRATION.md)。

Node固定为**16.13.0**，实测npm **8.1.0**，允许npm 8；根目录及本目录`.nvmrc`、前端`.node-version`、engines和生命周期检查防止误用其它Node。lock为npm8的v2格式。先通过行内提供的运行时切换方式激活对应版本，再执行以下命令；不要使用npm11重写锁文件。

三工程驻场适配详见[功能流程清单](../docs/三工程驻场功能流程适配清单_V1.0_2026-11-03.md)及[Excel跟踪表](../docs/三工程驻场功能流程适配清单_V1.0_2026-11-03.xlsx)。除菜单/请求/样式嵌入外，前1000候选筛选与UM导入的服务端能力需单独处理，不是仅替换API地址。

本目录独立安装、测试和构建，不需要Python环境或MySQL凭据。三个业务页面未来复制到客户现有前端工程。

```bash
npm ci
npm test
npm run build
npm run dev
```

Windows也可在仓库根目录使用`./scripts/frontend.ps1 version`、`./scripts/frontend.ps1 install`、`./scripts/frontend.ps1 test`、`./scripts/frontend.ps1 build`及`./scripts/frontend.ps1 dev`。脚本优先使用已激活的16.13.0，或本工作区忽略目录中的独立运行时；不下载软件、不修改系统Node，用完恢复当前进程PATH。

默认页面端口930。开发及preview的`/api/**`均代理到Java `http://127.0.0.1:6931/api/plan/**`，Java不可用时不会降级直连Python。`JAVA_GATEWAY_URL`可由启动器注入；行内`bank`模式必须明确提供该地址。静态构建不需要运行Java或Python。

浏览器继续使用相对`/api`路径。正式部署时客户网关／前端服务器也必须将该前缀映射到Java；Vite开发代理不是生产静态文件自带的代理。

页面请求集中在`src/api/`及`src/api.js`，界面、路由和状态分别位于`src/views/`、`src/router.js`、`src/models/`和`src/services/`。迁入客户前端时复用客户的请求、身份、路由和UI基础设施。

当前前端为**纯 JavaScript + Vue 2 选项式 API**，组件使用普通 `<script>` 及 `data/computed/methods`，不再依赖 TypeScript、`vue-tsc` 或 `@vue/composition-api`。共享选择状态由原生 Vue 2 模型维护；异步请求与缓存生命周期服务集中在 `src/services/`。独立启动入口为 `src/main.js`；嵌入宿主调用 `src/integration.js` 的 `createPlanningIntegration` 并引入 `integration.css`，统一注入现有 HTTP、Vuex、路由前缀、接口前缀、权限及异常处理。

本轮按确认范围迁移 JS 和选项式 API，行外 Vite 构建保留。复制业务源码到宿主时使用宿主现有 Vue CLI/webpack 构建；现场仍需核对其 Babel、模板编译器及 CSS 支持，不把行外构建成功当成宿主构建已通过。迁移与验收见[JS 与选项式 API 迁移记录](../docs/前端JS与选项式API迁移_2026-11-09.md)。

共用接口约定见[三工程契约](../docs/contracts/README.md)。

## UI建议稿实施（2026-11-07）

按全部7张11-6设计稿和最新确认口径实施，详见[逐项清单、原图及最新截图](../docs/UI设计稿对齐清单_2026-11-07.md)。该清单记录尚有差异的宿主组件及外壳，不宣称逐像素一致。

三个业务页面为独立可关闭页签，页面和抽屉不再显示面包屑。行外切换缓存状态、关闭移除缓存；配置草稿切换时保留、关闭时确认。编辑页保留“返回”及固定页底统一保存；行内嵌入不显示本地侧栏、顶部栏或自建页签，复用宿主页签协议。

配置默认只读，整页编辑统一保存。滚动统计窗口放在规则标题旁，条件及目标在查看态合表；编辑按阶段切换、支持上下界。共用摘要按条件组分块，突出数值、明确且/或及含/不含，展示不修改原规则。生命周期和标签各保留一个统一展开/收起入口，停用标签末尾折叠。

七处筛选默认展开，每项标签与控件左右同行，标签区域128px（含20px问号占位）、控件200px/高32px；文字右对齐，无问号保留相同占位。整项随容器换行，查询/清空末行右对齐；清空只清待查条件，查询才应用并回到第一页，不清已选内容。业务填写表单继续上下label，起止日期复用并校验先后。宽度是项目统一落地值，不是PNG精确标注。

人工策划返回与任务上下文同行，步骤条统一12px圆角、实色完成勾选，底部操作固定，保存后冻结条件及数量。非营销已选卡片保留间距、跨页选择累积；列表固定列宽和内部滚动，ID单行、标题大纲截断且全文可悬浮查看。营销单选与数量分块，压缩少量数据时的空白。模板保留CSV及UM号/账号ID规则，异常按原行号合表，支持下载与关闭。

时间列表的批次使用二级弹窗，再进入对应详情；支持Esc、焦点循环和返回。换题使用双列候选及共用操作时间线，确认后返回原计划显示更新结果。弹窗标题与范围同行，失败导出只保留底部一个入口，概览按“分类 / 数量”展示。按钮12px圆角，共享样式限定在`.planning-ui`内；弹层保留原位置锚点，修复页面更新时插入位置失效的问题。

Vue2兼容检查修正5个组件9处Vue3 `:deep(...)`写法；浏览器同时检查构建CSS、实际文字/控件坐标、列边界、气泡全文和控制台异常。

验证：48项前端测试、类型检查、构建、模拟宿主和53个隔离Java/H2页面状态通过，含768/1280/1920宽度及105标签、60条长选题的密集资料。临时证据在忽略目录`run/inside-host-browser/`及`run/frontend-host-acceptance/`，精选截图在文档目录。没有调用模型或写入开发业务库。真实宿主SearchForm、日期、上传和页签管理仍需映射，没有新增行内私有依赖。
