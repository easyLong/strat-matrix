# Java宿主接入准备：首轮完成情况

日期：2026-11-03。目标是将本项目的业务模块迁入客户现有Java工程；真实行内SDK、账号资料SQL、内容查询及调度SDK仍由现场实现。模板和逐项绑定见[java-backend/host-integration](../java-backend/host-integration/README.md)。

## 1. 统一Python能力客户端

- `PythonClient`集中处理服务地址、上下文路径、内部令牌、可信操作人、响应及异常转换；HTTP实现由宿主注入，公开参考实现提供连接/读取超时及禁重定向。
- 配置、自动策划、资料投影、后台唤醒客户端统一使用它；新增`ManualComputePythonClient`，人工计算不再与旧历史转接混在`LocalPythonAdapter`。
- 409/422保留给配置冲突处理，连接失败和不可用转换成稳定错误；不把上游响应头和原始网络异常输出给页面。
- 行外保留原构造参数兼容测试及发布工具，但正式装配共享同一个客户端。宿主无需使用`LegacyPythonProperties`。

## 2. 正式页面入口

- 新增`PlanningHealthController`，`/health`检查本项目业务MyBatis连接和Python数据库健康；两侧就绪时满足Vue原有初始化契约，故障返回503。不依赖旧通配代理。
- 新增`TagTaxonomyController`，显式提供标签读取/保存入口，标签及版本仍归Python维护；保存只使用宿主`Actor`，不信任浏览器请求头。
- Python标签写入口校验内部令牌，并保存Java提供的操作人；旧服务内部函数保留默认参数兼容已有调用。
- `PlanningApiErrors`统一补充页面错误语义；宿主统一响应包装和下载排除规则仍需适配。

## 3. 宿主装配

- 新增`PlanningHostConfiguration`及`inside`开关，正式导入配置、人工、自动、内容、查询、页面入口和任务服务。
- 宿主提供六类依赖：业务SqlSessionTemplate、同库事务管理器、HTTP客户端、`SourceFacts`、`Actor`、`HostAccess`。缺失时明确装配失败，无模拟回退或默认放行。
- 从local包提取`SourceCatalogAdapter`、`ContentFactsAdapter`、`ContentObservations`，让两环境复用资料映射与内容事实转换。旧类名仅为行外测试兼容包装。
- 宿主统一管理SSO和权限；`HostAccess`建立认证授权及数据范围上下文，数据范围还须由资料SQL与业务MyBatis实际执行，模板不伪造权限实现。
- 不迁入`standalone`、行外数据源、自动建表类、本地定时器、旧通配代理或私有运行配置。

## 4. 普通任务推进服务

新增`PlanningTaskService`，宿主直接调用`run(kind, now, limit, afterId)`。配置发布恢复、人工、自动、明日热点、自动营销引用、人工营销排期、普通内容状态、营销状态和算法唤醒各自为一次推进。

服务不注册定时器或线程池。分页结果返回`has_more/next_after_id`，失败时不推进游标；人工等待通过`needs_next_tick`要求下一次调度，避免立即循环；暂态问题显式返回需重试或抛错。受理信号、一次扫描和业务完成分开。

行外`LocalExecutionConfiguration`仅组织触发时间和游标，复用相同任务服务；每日热点检查继续只看明天。宿主按其Job规范接入，控制频率、重试、分页预算和监控，不能将HTTP202或`processed`一律当作业务完成。

## 5. 关闭行外组件的验收

`InsideThreePagesAcceptanceTest`加载正式宿主装配与全部业务模块，使用独立H2及生产Mapper/视图SQL，Python以受控HTTP响应桩提供契约结果，不访问开发MySQL或收费模型。

验收覆盖：

- 配置读取、保存、版本列表及恢复；标签查询、保存、版本冲突和可信操作人。
- 人工资料查询、冻结输入、提交、重复请求契约、计算受理与结果提交、正式业务结果。
- 账号列表、时间列表、账号/周期/批次明细、换题、调整记录及CSV导出。
- 全部任务阶段调用、分页游标、暂态失败和执行信号受理；来源鉴权、页面授权拒绝、依赖不可用。
- 六类宿主依赖逐个缺失时装配失败；无旧代理、本地脉冲、模拟文件资料或旧Python适配器Bean。

另外实际启动Chrome，通过测试专用回环MVC桥与静态代理访问当前Vue生产构建，检查三个页面及13个界面状态：配置只读/历史/编辑、人工列表/账号/选题/确认、账号列表/账号详情、时间列表/周期详情/批次详情/计划详情。等待接口加载完成，检查错误提示与JavaScript异常，生成截图和报告。测试桥与静态代理均不进入正式工程。

浏览器验收发现并修复：详情默认`planType=all`被当作具体值过滤，造成详情和概览为空；查询SQL现将其作为不限制方式处理，账号详情接口和实际日历数据均加验证。

证据在忽略的`run/inside-host-browser/`。接口/装配入口为`mvn test -Dtest=InsideThreePagesAcceptanceTest,PythonClientTest,PlanningTaskServiceTest`；浏览器开关和环境要求见模板说明。
