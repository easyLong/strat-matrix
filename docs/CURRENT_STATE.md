## 2. 工程与数据归属

| 位置 | 负责什么 |
| --- | --- |
| 本仓库 `frontend/` | Vue三个页面、共用组件、状态和交互 |
| 本仓库 `java-backend/` | Java开发壳、普通人工策划业务与独立库、其他业务的本地兼容适配 |
| 本仓库 `python-backend/` | FastAPI旧页面业务、Java资料读取适配、算法与自有库计算任务 |
| 行内已有Java工程（目标） | 接收本项目Java业务模块，复用登录权限、可信操作人、宿主Job及业务资料查询 |
| 本仓库 `docs/integration/java-host/` | 方法、对象和空方法参考模板，使用`.java.example`后缀，不参与编译 |
| 行内业务库 | 账号、选题、营销内容、互动、审核、投放和生产事实 |
| Java业务库 `strat_matrix_bus` | 首轮普通人工任务、正式批次和明细、换题记录及内容状态投影 |
| Python算法库 `strat_matrix` | 标签、画像、向量、匹配策略、计算任务；未迁移的历史业务数据暂留 |

目标调用关系为Vue → 行内Java → Python。Python经Java读取行内资料，不直接查询行内业务库。内容侧经独立授权读取策划结果并自行生产；普通人工的内容状态由宿主Java查询内容方后投影到Java业务库，其他历史链路暂沿用原有实现。
