## 文件怎么处理

| 目标工程 | 直接迁入或复用 | 在行内实现／替换 | 不迁入 |
| --- | --- | --- | --- |
| Vue | `frontend/src`中的三个页面、组件、类型和交互逻辑 | 行内路由／菜单、请求基址、登录会话、统一错误与下载处理；页面始终只访问Java | Vite本地代理和本地启动配置 |
| Java | `java-backend/godp-planning-services/src/main/java/com/pab/aitmp/aiis/godp/planning/services/manual/`、`src/main/resources/mapper/ManualMapper.xml`、经审批发布的`db/manual-business.sql` | 用宿主MyBatis工厂绑定业务库Mapper和同库事务；实现五个`ManualPorts`接口、身份权限、Java→Python客户端、宿主Job、路由前缀 | `standalone/**`、`adapter/local/**`、`adapter/legacy/**`、本地Parent、Hikari装配、运行期建表 |
| Python | `manual_compute.py`及后续打标、画像、向量、V2匹配等算法模块和内部契约 | 按行内Python工程组装算法路由、算法库连接、模型调用出口和受控唤醒；Java只通过内部HTTP调用 | 将当前含旧页面业务路由的`bootstrap.py`整包当作纯算法服务迁入 |

Java业务包仍含对`ManualPorts.Transition`的调用，但不含旧Python URL。普通人工业务所需的行外URL集中在`adapter/local/LocalPythonAdapter`，其余未迁业务的转发在`adapter/legacy`。`ManualPorts.Source`负责账号／选题事实，包括新明细换题候选；`Transition`只承接旧策划历史。历史需要保留时用行内数据或批准的过渡查询实现；明确无历史的新安装可显式注册`ManualNewInstallTransition`。`Computer`负责算法委托，`Actor`负责可信操作人，`ContentStatusSource`负责内容方状态读取。五个接口加`ManualDatabase`合计六个宿主输入Bean；缺失时应启动失败。

`ManualRepository`的MyBatis迁移已完成，驻场仍须核对宿主Mapper扫描和依赖树。这是一次独立的持久化适配验收，不属于仅换数据库连接。`ManualQueryService`合并新旧历史后在内存分页，当前不宜直接套PageHelper；历史退出后再把单库分页下推到SQL。

## 按这个顺序迁入

1. **固定宿主事实**：拿到实际依赖树、业务库数据源／事务Bean名、Python内部HTTP规范、前端路由与可信登录方式；决定旧历史数据保留还是迁移。
2. **先跑普通人工策划**：发布六张业务表，注册Mapper XML，提供`ManualDatabase`和五个端口；让行内Job调用人工任务推进。用一个账号与选题验收“提交→Python计算→Java落库→页面查询→XLSX导出”。
3. **处理过渡数据**：需保留历史时实现`Transition`的旧业务方法，核对旧批次号和新批次号不冲突；确认为无历史的新安装则显式使用`ManualNewInstallTransition`。历史迁完后把合并查询改为单库查询。
4. **逐条迁移剩余业务**：先业务配置和标签职责，再营销人工策划、自动周策划、热点T-1与内容状态。每迁移一条，Java接管对应页面API和正式业务写入，Python保留算法计算；移除相应的本地转发路径。
5. **三个工程联合验收**：Vue只到Java；Java只写业务库，Python只写算法库；调度由行内触发；失败、重试、权限、导出、回退均按现有页面契约验证。

## 复杂度判断

**第一阶段非营销人工策划：中等，可控。** Java业务状态机、MyBatis Mapper、Python人工计算接口和本地闭环均已存在，驻场主要工作集中在行内资料映射、身份权限、宿主MyBatis／调度和旧数据过渡。

**三个页面全部迁入：中高复杂度。** 配置、营销、自动策划与热点还保留在旧Python业务路由中；最大工作量是业务归属迁移及历史数据衔接，不是引入Excel、Hutool等已有依赖。不要用通配转发替代这些业务迁移。

需要客户尽早确认的只有影响实施顺序的四件事：行内业务库的Mapper／事务绑定方式；账号和选题的实际查询对象；旧历史结果如何保留；Java内部HTTP与Horae触发规范。其余通用工具包按已有工程依赖复用即可。
