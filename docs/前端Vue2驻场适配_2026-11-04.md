# 前端Vue2驻场适配与验收

日期：2026-11-04。客户指定Vue `^2.6.14`、Vuex `3.6.0`、Axios `1.8.2`、Element UI `2.15.13`，本轮已完成适配。实际lock和浏览器均为Vue2.6.14，编译器同版；不是以Vue2.7代替2.6。

本文保留Vue2迁移初次验收记录，当时使用Node24。后续已完成[Node16.13.0独立验收](前端Node16适配_2026-11-04.md)，当前以该运行时和npm8的锁文件为准。

## 变更

- 替换Vue3入口、Pinia及VueRouter4，采用Vue2构造入口、namespaced Vuex模块和VueRouter3.6.5；保留业务页面状态及返回列表页码。
- 组件转换为普通Vue2 TypeScript SFC，组合逻辑使用公开插件`@vue/composition-api@1.7.2`。移除Vue3宏、Teleport和命名v-model，适配单根模板、事件名称、`.sync`、路由守卫及过渡样式。
- 新增`BodyPortal`处理弹层挂载和销毁；修复Vue2下动态字典及面包屑响应式处理，营销数量通过事件写回父组件。
- 页面HTTP统一为Axios，保留Java相对路径、错误提示、取消请求和GET缓存控制。Element UI统一注册与加载主题，业务布局保留。
- 提供`installPlanningUi`、`attachPlanningStore`和`setPlanningHttp`，分别接入宿主UI、已有Vuex和统一Axios。模块内相对引用可直接随目录迁移。
- 行外构建使用支持Vue2.6的Vite4.5.14和vite-plugin-vue2 2.0.3。宿主复用自己的构建工具，不需要带入本地Vite或临时转换工具。
