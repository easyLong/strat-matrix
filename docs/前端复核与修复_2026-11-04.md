# 前端复核与修复

日期：2026-11-04。范围：Node16/Vue2迁移及遗留组件清理后的三个业务页面。

## 本轮修复

| 问题 | 影响 | 修复 |
| --- | --- | --- |
| 报表导出直接使用硬编码 `/api` 的 fetch | 注入行内 Axios 客户端后，导出仍绕过宿主地址前缀、鉴权及拦截器 | 新增统一 `requestBlob`，与普通请求使用同一客户端；保留二进制文件和响应类型，解析 Blob 中的 JSON 错误；网关非 JSON 错误显示状态码 |
| 中文数字实体编码在 Vue2 属性及表达式中直接显示 | 选择选题的 ID/标题输入提示、分页单位及部分辅助提示出现 `&#x...;` | 将账号选择、选题选择和计划详情组件中的中文数字实体改为 UTF-8 中文；浏览器验收检查页面文本及 placeholder/title/aria-label |
