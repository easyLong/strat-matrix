# UI 视觉规范 V1.0：三张图稿解读与落地

日期：2026-10-16。依据：客户提供的「基础」「组件：操作与表单」「组件：数据与反馈」三张设计规范图。适用范围：策划配置、手动策划、策划结果及其详情、弹窗和抽屉。

## 1. 总体原则

- 以 1440 × 900 桌面端、中高信息密度为基准。颜色表达状态、操作与层级，不承担无意义的装饰。
- 建立统一的颜色、字体、间距、圆角、阴影变量，组件使用变量派生。
- 维持已确认的业务流程、字段含义与页面入口。自动策划仍并入策划结果，不重新增加独立导航。
- 首先展示生效配置，进入编辑后才可修改。表格和配置在保持可读性的前提下紧凑，不增添提示性描述和刷新入口。

### 2.3 语义色

| 语义 | 前景 | 示例与使用规则 |
| --- | --- | --- |
| 成功 | `#0E9F6E` | 已完成、保存成功、数据已连接、非零完成数 |
| 推进中 | `#D97706` | 待生成、进行中、处理中、待人工确认 |
| 系统运行中 | `#2F4BE0` | 生产中、上传中、执行中生成任务 |
| 危险或异常 | `#E5484D` | 失败、校验不通过、危险确认、非零失败数 |

状态标签使用语义色约 12% 的浅底，不加描边。数字 0 保留浅灰色、普通字重，不能标红、标绿或使用告警底色。任务中实际存在失败项时可用极浅告警行底提示。

## 3. 字体与排版

首选 MiSans，同族字体显示数字和 ID；字距统一为 0。数字采用等宽数字 `tabular-nums`，避免计数和日期跳动。

| 角色 | 字号 / 行高 | 字重 | 场景 |
| --- | --- | --- | --- |
| Display | 26 / 34 | 600 | 封面、总览主标题 |
| H1 | 20 / 28 | 600 | 页面唯一一级标题 |
| H2 | 16 / 24 | 600 | 卡片、配置区块标题 |
| H3 | 14 / 22 | 600 | 表单分组、区内小标题 |
| Body | 14 / 22 | 400 | 正文、表单值、表格内容 |
| Body Medium | 14 / 22 | 500 | 账号名、按钮、关键列 |
| Caption | 13 / 20 | 400 | 表头、标签、辅助信息 |
| Micro | 12 / 18 | 500 | 状态标签、徽章、计数 |
| Numeric | 13 / 20 | 500 | 时间、比率、数量、ID |

时间显示统一为 `YYYY-MM-DD HH:mm:ss`，不直接展示 ISO 的 T 或毫秒；只有日期的投放日期保持 `YYYY-MM-DD`。

## 4. 间距与栅格

| 尺度 | 用途 |
| --- | --- |
| 4px | 图标与文字的最小间隔 |
| 8px | 控件内部水平间隔 |
| 12px | 表格行内元素间距 |
| 16px | 表单控件间距、表格列间距 |
| 20px | 卡片与区域间距 |
| 24px | 卡片标准内边距 |
| 32px | 页面内边距 |
| 40px | 大区域留白 |

- 导航宽 224px，顶部工具栏高 56px，内容自适应铺满。
- 导航项高 40px，左右内边距 12px，图标与文字间距 10px。
- 表格标准行高约 52px，横向间隔 16px；多行内容允许自然增高。
- 控件仅使用 32 / 36 / 40px 三种高度，主操作默认 36px，密集配置使用 32px。
- 日历与配置避免被统一放大：保留已确认的两列阶段卡片、紧凑标签和横向滚动。

## 5. 圆角与阴影

| 圆角 | 用途 |
| --- | --- |
| 4px | 小标签与色块 |
| 6px | 按钮、输入框、下拉框、状态标签 |
| 8px | 表格容器、内嵌面板 |
| 12px | 内容卡片、看板容器 |
| 16px | 弹窗、抽屉浮层 |
| 999px | 多选胶囊、头像、状态点 |

| 层级 | 阴影 |
| --- | --- |
| e1：静置卡片 | `0 1px 2px rgba(16,24,40,.04)`，搭配 1px 描边 |
| e2：可拖拽或悬停卡片 | `0 4px 12px rgba(16,24,40,.08)` |
| e3：下拉与气泡 | `0 8px 24px rgba(16,24,40,.10)` |
| e4：弹窗与抽屉 | `0 24px 64px rgba(16,24,40,.18)` |

阴影只表达层级，不能用装饰性彩色阴影。

## 6. 按钮

- 默认高 36px、圆角 6px、文字 14/22 Medium，图标与文字间距 6px。
- 主要按钮：primary-600 默认、primary-500 悬停、primary-700 按下；禁用使用中性浅底和弱色文字。
- 次要按钮：白底、中性边框；悬停使用浅品牌底和品牌边框。
- 文字按钮：表格行内操作，品牌色，悬停浅品牌背景；不在同一页增加重复的主要操作。
- 危险实心按钮只用于明确的危险确认，恢复版本可使用危险描边按钮，操作必须经二次确认。
- 加载按钮保留原宽度，出现旋转图标和进行中文案；禁止重复提交。
- 键盘焦点环统一为 3px 品牌色 14% 外发光。
- 图稿要求点击目标不小于 44 × 44：复选框通过整行命中区实现，紧凑控件使用相邻留白、容器或标签扩大操作区域，不能互相遮挡。

## 7. 输入框、下拉与搜索

- 默认高 36px、圆角 6px、横向内边距 12px，字段标签与控件间隔 8px。
- 默认、聚焦、校验错误、禁用状态必须可分辨；聚焦使用品牌描边与 3px 焦点环。
- 必填使用红色星号；错误在字段附近展示，不使用红色表示普通等待。
- 数值与单位后缀共同组成一个控件。
- 下拉菜单：白底、边框、e3 阴影；选中项浅品牌底、品牌文字和勾选标记。
- 搜索输入即筛选，图稿基准为 300ms，支持回车立即应用。
- 日期范围成组展示；未填值使用弱占位。粉丝数起止范围沿用同样的组合结构。
- 优先使用可访问的原生输入和选择能力，不能只做看起来可操作的静态控件。

## 8. 选择控件与视图切换

- 每周策划日使用多选胶囊：浅品牌底、品牌描边和勾选标记，不使用实心主按钮填充；至少保留一天。
- 键盘左右方向键在星期之间移动，空格切换选择。
- 复选框覆盖未选、已选、半选和禁用状态；只允许符合条件的账号选择。
- 行复选的命中区至少覆盖 44px 行高；表头全选按当前筛选结果跨页选择，不勾选已策划等不可用账号。
- 账号维度与批次维度采用分段控件；切换后保留已有筛选条件。
- 具体标签保持小巧、无圆点；点击标签在标签旁打开操作菜单，点击空白或 Esc 关闭。改名、启停属于编辑草稿，最后统一保存。

## 9. 数据、状态与反馈组件

### 9.1 状态与账号类型

- 状态标签高 24px、圆角 6px、文字 12/18 Medium、约 12% 语义浅底、无边框。
- 已完成绿，进行中橙，生产中靛蓝，未知灰，失败红；标记只表示业务阶段。
- 认证账号使用带认证符号的浅品牌标记；非认证使用中性描边。
- 非营销共享、营销独用使用中性主标识与弱色补充信息，不能与业务状态颜色混淆。

### 9.2 步骤条、标签页与返回

- 步骤条只用于手动策划的「选择账号—选择选题—提交」。
- 当前步骤品牌色，完成步骤可点击回退；未完成步骤不可跳过校验。
- T1–T5 使用下划线标签页，与账号/批次分段控件区分；T6 用户需求使用悬浮提示，展示模型识别规则，不切换内容区。查看态也保留该提示入口。
- 返回任务列表是次要操作；进入下一步要滚动到步骤条，保留当前步骤定位。

### 9.3 表格与分页

- 默认白底；悬停极浅中性背景；选中使用品牌色约 6% 背景并高亮账号名。
- 可选行支持整行勾选；按钮、链接与表单输入不触发额外的行勾选。
- 分页包含总数、每页数量、上一页、当前页、下一页；页码采用中性描边，当前页主品牌色。
- 账号数与历史记录多时保留分页，筛选后重置或修正有效页码，不能一次渲染全部详情。

### 9.4 周批次看板

- 批次之间有独立外框；标题行提供周期名称、日期范围和计划数。
- 列宽固定 186px，超出横向滚动；日期按周一至周日排列。
- 单条内容展示策划方式、内容状态、标题与核心属性；单条可以点击查看详情。
- 无计划的日期保留等高浅灰空格，显示简短空状态，不造成整个日历塌陷。

### 9.5 加载骨架

- 与真实内容区域和行高匹配，预留高度，避免加载前后跳动。
- 请求持续超过 800ms 才显示骨架；快速响应不闪动骨架。
- 请求进行中不能被误显示为「无数据」；已有结果静默刷新时保持内容。

### 9.6 空状态

- 使用浅灰容器、轻量中性图标与简短标题，必要时提供重新筛选或业务操作。
- 按本项目已确认偏好，不增加解释性长段落和独立刷新按钮。
- 异常需要明确错误反馈，不能降级成普通无计划；等待、无数据与正常业务状态分别展示。

### 9.7 确认弹窗

- 宽 400px、圆角 16px、e4 阴影、遮罩 `rgba(11,16,32,.45)`。
- 标题、说明和动作分层，危险操作使用警示图标。
- 按图稿的纠正规则，危险红色只用于「确认取消」「确认恢复」「放弃修改并离开」等危险动作；「继续编辑」是次要安全动作。
- 结合本项目已确认的按钮位置，「继续编辑」在右侧并默认聚焦；左侧为危险确认。按 Esc 和点击遮罩等同继续编辑。
- 弹窗应约束 Tab 焦点在其内部，关闭后恢复原焦点。不能使用浏览器原生确认框。

## 10. 本轮实现记录

1. 统一靛蓝和墨阶变量、语义色、字体层级、圆角与阴影；替换历史样式中的零散色值。
2. 统一导航、工具栏、卡片、表格、表单、标签、分段控件、分页和周日历。
3. 修正生产中与未知状态配色、取消编辑弹窗的危险语义及默认焦点。
4. 增加延迟骨架、表格整行选择与跨页全选、可回退步骤条和键盘操作。
5. 已随前端部署小米官方 MiSans VF 简体中文与 Latin WOFF2 字体，共 56 个官方 Unicode 分段、约 4.52 MB。浏览器只请求当前页面用到的分段，字体通过本站静态资源加载，不依赖用户安装字体或外部 CDN。保留 `font-display: swap` 和系统字体回退。来源见 [MiSans 官方页面](https://hyperos.mi.com/font/zh/)，许可协议和使用声明在 `frontend/public/fonts/misans/LICENSE.pdf`、`frontend/public/THIRD_PARTY_NOTICES.md`。

## 11. 核对与业务口径

- 图中的“活动统计窗口 / 天”为控件示例。本项目继续使用已确认的“滚动统计窗口 / 篇”，没有因换样式改变统计口径。“热点选题占比”沿用已确认的新名称。
- 前端类型检查与生产构建通过。官方字体随构建复制，已在浏览器核对 MiSans VF 实际加载。
- 逐页核对：配置查看、配置编辑、配置历史、取消编辑弹窗、手动任务列表、账号选择、选题选择、账号维度、批次维度、账号历史和批次详情。
- 交互核对：星期方向键、弹窗默认安全焦点和 Tab 循环、Esc 安全退出、整行选择、跨页全选与半选、回退步骤、搜索防抖与回车立即筛选、切换维度保留筛选、恢复取消前的配置草稿。
- 数据展示核对：零值中性、生产中靛蓝、未知状态灰色、正常时间格式、周一至周日排列、186px 日历列宽、账号名称普通文本与独立结果入口。
- 模拟慢请求核对：800ms 前不闪骨架，超过后显示 52px 骨架行，完成后切回真实数据；加载期间不误显示空状态。
- 布局核对：1440、1100、780、375px；生命周期编辑控件不被裁切，表格和日历在各自容器横向滚动，页面本身不横向溢出。
- 核对过程中没有保存配置、创建真实策划任务或触发内容生产。
