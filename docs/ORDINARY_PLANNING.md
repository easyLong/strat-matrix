# 周度规则策划首版

本版可由服务器命令或独立调度进程触发。它读取当前服务端配置和最近一次同步的账号、普通及营销选题本地副本，为目标周的每个账号按“每周策划日”生成槽位。运营可在“AI 自动策划”和“策划结果”页面查询批次。

## 首次部署

在项目根目录执行结构更新；新表和新增字段均带中文注释：

```bash
cd backend
python3 -m app.init_db
```

若使用虚拟环境，将 `python3` 换为 `.venv/bin/python`。

## 触发下一周策划

仅需要普通内容演示数据时，保留原命令：

```bash
cd backend
python3 -m app.ordinary_planning --scope demo
```

正式周策划使用：

```bash
cd backend
python3 -m app.weekly_planning
```

可用 `--cycle-start 2026-10-12` 指定目标周的周一日期。只允许策划下周或更晚的完整自然周。已有正式自动批次时会复用已登记的结果或拒绝叠加，不会重复插入槽位。

## 自动调度

Linux 部署时 `./start.sh` 默认启动 `ordinary-scheduler` 周策划进程和 `hotspot-scheduler` 热点进程；`./stop.sh` 和 `./status.sh` 同时管理它们。周策划进程每分钟读取服务端当前配置，按北京时间检查 `schedule_day` 与 `schedule_time`。到时为下一自然周执行正式数据范围的规则策划；本周到时后启动也会补跑，过了本周不会为过去的周期补跑。同周多进程触发由数据库锁和唯一运行记录去重。

缺少正式同步账号或普通选题、数据库暂不可用等情况会写入 `logs/ordinary-scheduler.log`，一小时后重试。演示数据不会进入自动调度。可以设置 `.env` 中的 `ORDINARY_SCHEDULER_ENABLED=0` 并重启脚本，停用该进程。单次按当前配置检查可执行：

```bash
cd backend
python3 -m app.ordinary_scheduler --once
```

热点进程每分钟检查已到 T-1 22:00 的正式热点空槽。它只在有待定空槽时读取最新成功的 IF-04 快照；从未成功同步会记录异常并于五分钟后重试，成功空快照则使用普通最热选题兜底。执行结果写入 `logs/hotspot-scheduler.log`。已确定的槽位不会重复改动；若错过触发时间，启动后会补处理仍未发布的待定槽位。可在 `.env` 设置 `HOTSPOT_SCHEDULER_ENABLED=0` 后重启服务停用，或手动执行一次：

```bash
cd backend
python3 -m app.hotspot_scheduler --once
```

## 数据准入与结果

- 账号须有本地同步来源、账号档案处于启用状态，且来源记录未停用。IF-01 账号同步支持 `is_marketing_account`，也兼容原有 `marketing_eligible` 字段；演示与正式账号分开处理。
- 普通选题须有本地同步来源、目录可用、当前有效、未停用且不是营销选题；演示与正式选题分开处理。
- 选题按来源 `topic_heat` 从高到低排序，同热度按选题 ID 排序；同账号一周内优先使用不同选题。缺少热度时按 0 处理。
- 生命周期优先使用 IF-01 账号同步的近三个月帖子级互动快照；旧账号未提供 `interaction_data` 时兼容独立历史内容同步记录。单篇互动数为红星、收藏、评论之和，滚动窗口使用配置的篇数。结果保存策划时的阶段和经营作用快照。
- 全局热点空槽数按总槽位数乘热点占比四舍五入，使用可复现随机顺序选择具体账号和日期。热点槽位在周策划时不绑定选题，也不会进入 IF-05 可生产结果。
- 非营销账号不规划营销槽位。有营销资格的账号须有成功的 IF-03 同步记录；成功空快照表示本次没有营销候选。营销槽位数取本账号已同步且启用的营销候选数、周上限和剩余非热点槽位数的最小值，随机落位。已审核且有效的营销选题按审核通过时间升序使用；合法选题不足时，槽位保留营销类型、实际选题类型记为普通。
- 其余槽位使用普通选题热度兜底，同账号优先使用不同选题。每条结果冻结实际选题类型、大纲、内容类型及经营阶段；批次、槽位、当前版本和输入快照在同一事务中写入。批次备注明确标记未执行 AI 匹配。

本版尚未运行向量匹配。普通和营销结果不自动发送内容生产任务。正式结果查询和发布回传已有[本地对接接口](IF05_IF06_本地对接契约.md)，客户的最终技术协议仍待确认。
