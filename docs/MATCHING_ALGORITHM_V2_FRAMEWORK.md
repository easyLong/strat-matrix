# V102 匹配算法框架 V2

状态：组合目标 V2 已接入 Matching Task 执行 Worker，使用独立实现标识 `builtin-cosine-portfolio-v2`，须创建并批准专属策略后才会执行。完整 T1–T6 账号特征适配仍未接入；V2 当前以 cosine 作为候选 Fit，使用 T3/T4/T5 稳定选题标签计算覆盖度。现有 `builtin-cosine-balanced-v1` 执行链与已保存的 V1 策略、任务和结果保持不变。

## 目标链路

```text
冻结输入
  → Hard Gate 候选过滤
  → 多属性 Fit 评分
  → MMR 相关性与多样性控制
  → 全局槽位/选题矩阵分配
  → 账号组合效用评估
  → 审计提案
```

算法原语位于 `backend/app/matching_algorithm_v2.py`；生产适配器位于 `backend/app/matching_executor_v2.py`。它消费 Matching Task 已冻结的输入并保存匹配提案，不直接创建任务、不提交正式策划批次，也不调用内容生产服务。

## V102 方法与代码组件

| 方法步骤 | 代码组件 | 职责 |
| --- | --- | --- |
| Hard Gate | `HardGate` 协议、`score_candidates` | 由业务策略判定账号-选题边是否可进入候选集；排除原因单独保留 |
| 多属性 Fit | `FeatureExtractor`、`FitPolicy`、`weighted_fit` | 对命名特征按已确认权重计算分数，并输出逐项贡献 |
| MMR | `mmr_utility` | 根据候选相关性与其对已选选题的最大相似度计算增量效用 |
| 全局矩阵分配 | `allocate_matrix` | 在槽位、账号-选题复用上限、选题全局容量下做全局效用分配 |
| 组合效用与改进 | `matching_portfolio_v2.py` | 计算相关性、覆盖、槽位质量平衡、冗余，并在容量约束下做确定性局部改进 |

全局分配采用最小费用增广路径，最大化总效用；未分配槽位的效用按 0 处理，效用相同时按稳定顺序处理。当前矩阵分配器是可替换的基线组件。若评审要求将 MMR 或组合效用直接纳入全局求解目标，需要实现新的 `MatrixAllocator` 策略，并以同一冻结输入做对照评估。

## 特征边界

Fit 的维度名由策略显式提供。实现不会假设 `T1–T6` 与 persona、目标客群、兴趣、表达风格之间的权重或一一映射，也不会把某个标签相同直接解释为硬过滤条件。

`FitPolicy` 要求：

- 特征权重必须显式提供、非负且总和为 1；
- 缺失值处理必须明确选择 `reject` 或 `renormalize`，不支持补零；
- 必须提供最低权重覆盖率，覆盖率不足的候选边不进入分配；
- 特征分值必须是 `[0, 1]` 范围内的有限数字；
- 每条候选边返回权重贡献，便于运营解释和后续校准。

MMR 的 `relevance_weight` 必须由策略提供；相似度必须来自已声明的语义空间并处于 `[0, 1]`。本模块没有内置推荐权重、相似度阈值或标签默认值。

T1–T6 的账号证据映射、Hard Gate、缺失口径和复用草案见[策略契约草案](MATCHING_POLICY_V2_CONTRACT_DRAFT.md)。
组合目标公式和 MMR 定位见[组合目标草案](MATCHING_PORTFOLIO_V2_DRAFT.md)。

## 输入与输出

算法层只接受上游准备完成的冻结对象：

- 账号画像、选题画像和各自向量；
- 槽位 ID、账号 ID、投放日期；
- 标签/业务规则的版本及可审计字段；
- 正式选题使用次数和历史引用事实（如策略要求）；
- Fit 权重、缺失信号口径、MMR 参数、复用容量和组合效用策略。

`score_candidates` 输出候选边与 Hard Gate 排除原因；`allocate_matrix` 输出槽位到选题的分配；组合效用由注入的 `PortfolioUtility` 计算。运营展示仍由现有结果模型负责，Fit 细项和排除原因应保留在审计数据中，不直接扩展为运营页面字段。

## 尚未接入的部分

V1 任务的 `MatchingEvaluation` 仍使用固定五阶段审计结构；Worker 按实现标识分流 V1 与组合目标 V2。组合指标摘要复用既有五阶段结构持久化，不改变提案数据模型。

以下参数仍需业务/算法评审后才能形成可执行策略：

1. Hard Gate 条件、空值口径及拒绝原因枚举；
2. Fit 的维度映射、权重、特征算法和缺失值处理；
3. MMR 相似度来源、尺度、相关性权重及组合顺序；
4. 全局选题容量、账号内重复规则和无法分配时的处置；
5. 账号组合的覆盖、平衡、冗余定义和对应效用函数；
6. 评估指标、人工标注集、离线对照方式和可接受阈值。

这些值不能从现有一次 V1 测试结果倒推，也不从 V102 示意图推导默认参数。
