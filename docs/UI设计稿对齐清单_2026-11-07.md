# 11-6 设计稿与前端对齐清单

日期：2026-11-07。依据用户提供目录中的全部 7 张 PNG，按 3 倍图对应的桌面布局理解。本文同时记录设计稿中的结构、此前已确认的规范，以及本轮落实方式。

## 采用顺序

1. 用户已确认的交互口径：整页编辑、统一保存；业务填写表单 label 在上、控件在下；筛选项的标签和控件左右同行、固定宽度；按钮圆角 12px；查询手动触发、操作靠右；保存后冻结条件；营销只选一个选题。
2. 行内规范：主色 `#3177FF`，成功 `#00A870`、警告 `#FF810D`、危险 `#E34D59`；系统字体；32px 小控件；复用宿主请求、路由、权限与组件。
3. 本次设计稿：用于内容分区、卡片、步骤、表格、抽屉与信息层级。图片中的紫色替换为项目语义色；填写表单使用上下布局，筛选项按左右同行展示。

顶部平台主导航、员工登录信息、多页签和运营中心菜单由宿主提供。嵌入模式继续使用宿主外壳，业务模块只提供自己的三个页面与内部导航。

## 导航更正：三个独立页签

最新确认：AI策划配置、人工策划、策划结果是三个平级、独立打开和关闭的页签，不使用“父级 > 子级”导航。此口径覆盖本文件早先关于面包屑的描述。

- 行外独立运行：点击侧栏打开对应页签；同一个页面只打开一份，重复点击回到已有页面及其查看范围。切换使用 Vue keep-alive 保留页面状态；关闭时移除该页缓存，再次打开重新创建。
- 关闭当前页签切换到相邻页面；关闭非当前的普通页签不改变当前页面；全部关闭后主区域留空，可从侧栏重新打开。
- 配置草稿切换页签时保留，关闭配置页签时确认；继续编辑取消关闭，确认关闭才放弃草稿。关闭后台有草稿的配置页时先激活该页，让确认框可见。
- 移除页面、详情抽屉、导出弹窗里的面包屑。新建和编辑页使用“返回”，详情使用已有返回按钮，抽屉使用关闭按钮。编辑配置补回“返回”入口，仍通过确认后退出编辑。
- 行内嵌入：不显示子模块侧栏、独立顶部栏或自建页签，直接使用宿主的页签管理。三个业务路由提供 title、closable、keepAlive、tabKey 元数据；宿主按自己的页签协议接入，不能仅凭元数据认定真实宿主关闭/缓存行为已经验收。

同时修复了弹层根节点直接移到 body 后，Vue 在页面更新时可能使用失效插入位置的问题。BodyPortal 现在保留原位置锚点，只移动内部弹层；页面切换仍隐藏弹层，销毁时清理。

本次通过 45 项前端测试、类型检查与构建、50 个隔离浏览器页面状态及模拟宿主验收。截图：[三个平级页签](design-references/2026-11-07-result/workspace-three-tabs.png)、[关闭草稿确认](design-references/2026-11-07-result/workspace-confirm-close.png)、[全部关闭](design-references/2026-11-07-result/workspace-all-closed.png)。

## 第二轮视觉与长数据优化

继续保留三个独立页签、固定宽度右对齐筛选、整页编辑统一保存，以及现有业务字段和流程。本轮处理：

| 位置 | 修正内容 |
| --- | --- |
| 生命周期查看与编辑 | 提取共用 `LifecycleRuleSummary`。每个条件组使用独立浅色标签，组内显示“且”，组间显示“或”，数值强调；上下界组合显示并保留含/不含；兜底沿用原有说明。展示时只规范化副本，不修改已保存规则 |
| 配置页 | 减少生命周期、标签区域的重复套框，改为自然分区和分隔线；清理旧表格列宽规则，使阶段、条件、目标列一致 |
| 人工策划步骤条 | 完成步骤改为实色勾选，当前步骤文字突出，容器统一12px圆角；步骤和保存行为不变 |
| 营销选题与数量 | 列表最小高度由240px压缩到160px，保留最大高度和内部滚动；数量输入统一32px高度、12px圆角；桌面常规数据下选题和数量能同时看到 |
| 已选选题 | 多张卡片之间增加10px间距，保留完整边框，卡片不被滚动容器压缩 |
| 长选题列表 | 使用固定列宽，ID单行，标题、大纲分别限制在自己的列中，避免文本穿过相邻列；标题气泡、大纲及其他长字段悬浮保留完整信息 |
| Vue2样式兼容 | 发现并修正5个组件中的9处Vue3 `:deep(...)`写法，改为Vue2支持的`::v-deep`；检查构建CSS，确保深度选择器已被编译，实际作用到子组件 |
| 标签密集内容 | 长分类名称和长标签截断并保留完整悬浮信息；保留一个全局展开/收起，停用项在末尾折叠 |

## 再次复核：文字右对齐与差异进展

本次重新对照七张原稿及当前浏览器截图。上一轮只检查标签框、输入框宽度和同一行布局，没有检查文字的实际右边缘；带问号的标签把文字与问号一起排版，不带问号的标签没有相同占位，因此文字末端仍然不齐。不能仅凭 CSS 中存在 `text-align:right` 就认定已经符合设计。

### 本次修正

| 位置 | 核查发现 | 处理结果 |
| --- | --- | --- |
| 七处筛选区 | 有问号、无问号的标签文字右边缘不一致 | 标签区域统一 128px，其中预留 20px 问号区域；文字在剩余区域右对齐，问号独立定位。没有问号时保留等宽空位，不向字段名称补空格、不删改名称 |
| 七处筛选区 | 仅凭截图判断，不能证明实际对齐 | 浏览器增加文字 Range 测量，检查文字右边缘、问号位置、标签宽度、控件宽度和垂直中心；包含日期与粉丝范围控件 |
| 人工策划选择选题 | 有效期在列表上方整段重复说明，表头又有问号 | 保留有效期表头问号提示；非营销仍按投放日期、营销仍按当天校验，可悬浮或聚焦查看完整口径 |
| 替换选题 | ID、分类、有效期混成一段小字；大纲名称与正文粘连；截断内容缺少完整提示 | 改为独立的小标签；补全“选题大纲：”分隔；标题与大纲支持悬浮查看完整内容 |

128px / 200px 是本项目此次统一落地的标签区域/控件宽度，不是从 PNG 中精确量取的设计标注。常规容器内固定宽度，整项换行；只有容器不足以容纳整项时收缩控件。固定的是区域宽度，不是强制把不同名称变为相同字符数。七处范围为任务列表、选择账号、选择选题、结果账号列表、结果时间列表、策划详情和替换选题。

### 差异处理进展，仍不代表逐像素还原

| 位置 | 当前与原稿的差异 | 后续处理边界 |
| --- | --- | --- |
| 编辑配置的生命周期摘要 | 原为一整段规则预览，第二轮已按条件组拆成浅色标签、强调数值 | 查看与编辑共用；组内且、组外或及含/不含边界保持 |

| 步骤条 | 第二轮已改为实色完成圆点和12px圆角 | 步骤跳转、保存及冻结行为保持 |

| 营销选题页首屏 | 第二轮已压缩列表留白，桌面常规数据下数量区可见 | 窄屏仍通过页面滚动操作；长列表维持内部滚动和分页 |

| 行内宿主外壳 | 行内顶栏、菜单、多页签与本地独立开发外壳不同 | 嵌入后复用宿主提供的外壳，不在子模块重复实现平台导航；需在真实宿主验收 |

颜色使用此前确认的行内蓝色；业务填写表单使用此前确认的上下 label；筛选维度使用本次明确的左右同一行、固定宽度、文字右对齐。营销单选、整页统一保存、保存后冻结等已确认交互保持。这些属于明确采用的需求口径，区别于上表尚待精修的视觉差异。

本次验证：45 项前端测试、类型检查与构建，以及 46 个隔离浏览器页面状态通过。对齐校验直接测量渲染结果，覆盖不同长度标签和带/不带问号的情况；没有修改开发业务库或调用真实模型。

## 控件与布局规则

| 对象 | 本轮统一规则 |
| --- | --- |
| 填写表单 | label 上、控件下，间距 8px；单位、T−、范围分隔符属于控件内部，可同行 |
| 筛选项 | 每项为“标签＋控件”左右同行。标签宽128px、右对齐；控件宽200px、高32px；间距8px。空间不足时整项换行，极窄容器才收缩控件，标签和控件始终同行 |
| 查询 | 常开筛选；末行靠右放清空、查询。清空只清输入，点击查询才应用，保留已选内容 |
| 选择列表 | 结果数量只保留一处；表头固定，表体限制最大高度；宽表内部左右滚动，分页不随表体滚出 |
| 长文本 | 列表标题、大纲及标识截断；悬浮可读全文；大纲在详情中完整展示 |
| 卡片 | 12px 圆角；浅色背景承载摘要及选中信息；边框表达区域层级，避免大面积阴影 |
| 弹窗/抽屉 | 标题与上下文统一字号，使用“标题 - 上下文”；正文滚动，主要操作固定；保留关闭入口 |
| 步骤 | 营销为创建—选题—确认；非营销为创建—账号—选题—确认；已完成步骤可返回，保存/下一步维持原有交互 |
| 空、异常、禁用 | 空列表保留稳定高度；异常显示原原因；保存后条件不可修改；已进入生产或已完成内容不开放换题 |
| 自适应 | 覆盖 768、1280、1920 宽度；筛选项随容器换列；窄屏候选卡由双列切为单列 |

## 生命周期范围编辑的保存口径

- 展示转换：同一条件组内、同一指标的上下界可组合为一行；不同条件组之间不合并。
- 原有 `>`、`≥`、`<`、`≤` 的边界继续保留，标签明确写“含”或“不含”；等于条件独立展示。
- 缺少某一端显示“不限”。新增下界写入现有 `gte`，新增上界写入现有 `lte`，沿用现有条件字段及接口。
- 清除双边范围的一端后保留另一端；清空最后一个边界视为未完成编辑，阻止保存。删除条件使用明确的删除操作，不能把整个阶段删成空规则。
- 阶段优先顺序、冷启动兜底、经营目标与实际配置值保持原口径。起始值大于截止值、空值和非法整数在页面提示并禁止保存。

## 设计稿与已确认需求的差异处理

| 设计稿里的内容 | 采用口径 |
| --- | --- |
| 紫色品牌、横排表单 | 使用行内蓝色；业务填写表单上下 label，七处筛选区统一固定宽度、左右同行 |
| 内容策划配置 | 保留此前确认的名称“策划内容配置” |
| 编辑态底部恢复/取消/保存 | 保留统一保存入口；未保存离页仍确认，通过面包屑可返回，不重新增加顶部取消按钮 |
| 阶段及经营目标示例数字不完全一致 | 展示和编辑当前保存的配置；条件与经营目标按阶段名称对应，不按行号关联 |
| 营销列表画成多个复选框 | 保留营销单选和一个选题的生成数量，业务规则不随示意图改变 |
| 模板示例“22、10、2、11” | 使用实际识别结果，不能照抄不满足分类数量关系的示例数字；重复行与异常行分开统计 |
| 换题摘要使用发布状态、表单重复选题类型/关联产品 | 使用内容状态，保持一个选题类型、关联产品及关联活动字段，不复制重复项 |
| 多个“展开/收起”入口、重新出现已选计数文案 | 分类区域沿用统一展开/收起；已选区域仅展示数量徽章，查询结果数量单独保留一处 |
