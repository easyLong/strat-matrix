# 数营平台 UI 规范与现有页面差异清单

依据：数营平台基础规范 2026-10-20 的全局样式、导航、数据输入、数据展示、数据反馈五张规范图。项目作为平台嵌入页面，平台导航及登录由宿主负责。

| 范围 | 数营平台规范 | 调整前的项目 | 本轮处理 |
| --- | --- | --- | --- |
| 主题色 | 主色 #7860FE，辅助色 #4E1AA5 | 蓝色 #2F4BE0 | 更新主题及状态色变量 |
| 文字 | 中文苹方，英文数字 Helvetica Neue，正文 #262626 | MiSans 与蓝灰文字 | 调整字体栈与中性色 |
| 布局 | 12 栅格、4px 间距体系，常用 12/16/24px | 卡片间距和内边距偏大 | 缩小页面及卡片间距，保留业务布局 |
| 卡片与控件 | 页面卡片、按钮、输入框 4px 圆角，信息卡片 12px | 卡片 12px、控件 6px | 统一公共卡片和控件，信息卡保留层次 |
| 按钮及表单 | 按钮 32px，输入框有悬浮、聚焦、禁用和错误状态 | 按钮和输入框 36px | 统一公共尺寸与状态色 |
| 配置页 | 查看与编辑区层级清晰，使用规范按钮和表单 | 操作与组件沿用旧色 | 应用公共变量并收紧生命周期与配置间距 |
| 人工策划 | 表单、选题、账号选择和表格样式统一 | 行高、间距和颜色混用 | 调整步骤条、列表、表单和选择区 |
| 策划结果 | 表格长文本省略并提示，重要列固定，状态颜色一致 | 页面及卡片使用旧色和较大圆角 | 调整表格、批次和日历卡片外观 |
| 提示和弹层 | 按 Alert、Message、确认框、抽屉等场景区分 | 自定义弹窗与提示 | 统一颜色、边框和层级，保留已有业务操作 |

规范图的色板与文字示例中，链接色和成功提示色存在不同数值；本轮优先采用全局色板。真实平台字体可用性和宿主导航尺寸需在嵌入环境确认。

本清单记录样式对齐，不代表业务规则、接口或生产链路已经验收。页面中按业务需要保留的筛选、确认和异常提示继续使用。
