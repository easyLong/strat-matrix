# 页面资料查询迁入 Java V0.1

日期：2026-11-02。

人工策划页面所需的账号、选题资料现在由 Java 显式提供页面接口。Vue 仍请求原路径，响应对象不变。行外 Java 通过只读适配器复用现有 Python 资料源；驻场将该适配器替换为行内 Java 查询方法，不复制行内账号或选题主表。

| 页面能力 | Java 路径 | 输入 | 返回 | 驻场资料来源 |
| --- | --- | --- | --- | --- |
| 账号列表 | `GET /api/plan/accounts` | `limit`（1～1000）、`include_disabled` | 账号对象数组 | 行内账号、人设、组织资料查询 |
| 选题候选 | `GET /api/plan/topics` | `limit`（1～1000） | 当前可选选题对象数组 | 行内普通、热点及营销选题查询 |
| 选题详情 | `GET /api/plan/topics/{topicId}/detail` | 选题 ID、可选 `topic_type`（普通／营销／热点） | 单条选题对象 | 行内选题或营销内容详情查询 |

选题详情允许查看已不在候选列表中的历史选题；真正提交和换题时仍由冻结快照与资格规则校验，不能用详情接口代替校验。账号列表的 `include_disabled` 参数只影响查询范围，策划资格由提交时校验。

`ManualPorts.Source` 新增 `accountOptions` 和 `topicDetail`，并复用原有 `topicCandidates`。这三个方法是现场资料接入点；业务 Controller、Vue 请求路径及页面对象结构无需因行内 SQL 改写。旧页面通配转发白名单已移除这三个路径，避免绕过 Java 接口。行内账号与选题的字段映射、数据权限和稳定分页仍需按实际表结构接入。

当前本地 Java 业务表的 V3 结果槽位迁移及营销任务表尚未发布到远端业务库；本次资料查询改造不变更数据库结构，也未切换正在运行的服务版本。
