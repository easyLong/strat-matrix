# 服务内后台执行 V0.1

## 当前运行口径（2026-11-03）

Java负责业务推进和正式结果，Python只执行持久化算法/计算任务；仍只运行Vue、Java和Python三个服务。普通人工/自动任务、配置发布、营销衔接和内容状态由Java推进，Java按需发送`manual_compute`、`planning`等执行信号给Python。HTTP202只代表信号受理，业务是否完成以持久化任务为准。

热点由宿主每天调用Java业务服务，只检查北京时间明天的热点空槽，无空槽即结束；有则补题或采用冻结普通兜底。没有22:00门槛、不自动补扫过去日期。行外`LocalDailyHotspotCheck`在本地脉冲上模拟每日一次，分页完成后当天停止，异常可重试；重启后可重新检查，明细状态及版本防止重复处理。行内不迁入该模拟器，实际每日运行时间由宿主配置。

当前入口和证据见[全流程对照](全流程测试与行内接入对照_V1.0_2026-11-03.md)、[营销/热点验收](营销热点与模拟内容衔接验收_2026-11-03.md)。下面是2026-11-02迁移阶段历史，旧Python业务流向和当时测试数量不作为当前主链说明。

日期：2026-11-02。现在只运行Vue、Java和Python三个服务，取消独立常驻Worker。

普通人工策划的新迁移路径见[首轮Java闭环](JAVA_MANUAL_MIGRATION.md)：Java保存业务任务，由宿主调度调用advance；Python新增manual_compute角色，仅计算建议。下面manual角色仍用于旧队列收尾。

## 调用与归属

```text
人工提交 → Java页面入口 → Python旧业务提交并持久化 → 发出manual执行信号
本地Java开发调度／未来客户Job → Python内部唤醒 → 服务内受控执行器
执行器 → 原数据库队列、租约、重试、准备断点 → 正式结果与业务状态
```

Python启动时只创建执行器，不启动任何扫描或定时循环。Java本地`local` profile按人工2秒、主流程10秒、周／热点60秒发出触发，网络或鉴权失败会重试；非local模式不装配此模拟调度。驻场只迁移唤醒客户端，实际频率和触发由客户已有调度系统管理。

周检查、热点业务判断及主流程处理仍复用现有Python业务函数，尚未宣称这些业务已经迁入Java。本轮改变执行承载和触发方式。

## 内部接口

两个入口均要求`X-Integration-Token`，密钥仍来自MySQL。Java页面白名单不开放这些入口。

`POST /api/internal/wakeup`，请求：

```json
{"jobs":["manual","planning","weekly","hotspot"]}
```

响应202示例：

```json
{"status":"accepted","accepted_jobs":["manual"],"coalesced_jobs":["planning"]}
```

允许上述四种角色及新增manual_compute，拒绝未知字段和角色；默认仍选择旧四种。新计算接口受理后主动唤醒manual_compute。信号只要求执行一次有限扫描，不是新增业务任务，不返回虚构业务任务编号。202表示信号受理，不表示策划完成。

`GET /api/internal/executor`返回进程当前是否接收信号、运行／排队角色、累计扫描次数、失败次数及最近完成时间。该监控数据属于当前进程，重启后重新计数；正式任务、计算任务及失败详情继续从原业务接口和数据库查询。

## 并发与恢复

- 最多两个角色同时执行，每种角色最多一个Future，五种角色合计最多五个运行／排队信号；重复唤醒合并，不无限堆积。
- MySQL会话锁避免不同API进程同时执行相同角色；原有人工任务租约、流程锁和条件更新继续生效。
- 人工请求先提交数据库事务，再通知执行器。通知失败或服务正在停止时保留受理结果，后续Java脉冲重新扫描。
- 停机停止接收新信号，取消未开始的信号，等待正在运行的有限处理结束。强制终止后，任务租约到期再领取，准备和匹配继续使用已有断点／版本保护。
- Python重启不会自行轮询；自动恢复依赖后续Java／客户调度触发。只有Python而没有宿主触发时，自动检查及延迟重试不会自行运行。
- 处理成功表示一次扫描结束，不能替代业务完成状态；故障角色不影响其它角色后续执行。

正常启动使用三个子项目README中的命令。根目录start.sh只启动三个服务，发现旧Worker PID仍运行时要求先stop；stop.sh保留清理旧PID的兼容操作，status.sh不再要求Worker进程存在。旧统一Worker默认命令已停用，显式`--once`仅供诊断。
