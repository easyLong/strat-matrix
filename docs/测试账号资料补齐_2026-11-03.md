# 测试账号资料补齐

本轮补齐行外夹具中的90个账号。已有值保留，缺失值补为明确的模拟资料；没有添加业务线、地域等已取消的字段。

完整字段：账号ID、昵称、属主UM号、二级分行组织、平台、认证类型、粉丝量、可参与策划状态、人设、性别、兴趣、表达风格、更新时间和互动明细。互动样例包含内容ID、标题、发布时间、点赞、收藏、评论和更新时间。

修复了两处展示映射：

- 自动策划快照的基本信息位于`source_payload`，通过公共`AccountSnapshotView`转换为页面字段，账号详情、批次详情、导出复用；SQL视图同步兼容嵌套来源，UM号、组织、平台和认证类型筛选与展示一致。
- 账号列表按当前页账号ID批量读取当前基础资料，补齐性别、兴趣、表达风格、互动和账号状态。生命周期及趋势保留对应策划快照值，与现有SQL筛选保持一致。详情中的历史指标仍按冻结输入展示。

资料补齐工具：

```bash
python -m testing.complete_accounts
python -m testing.complete_accounts --apply
```

仅适用于outside。执行前自动备份，重复执行没有变化时不重写文件。当前备份与补齐记录在`run/backups/account-facts-20261103-043947/`，均为私有测试文件，不提交Git。

以后全链路测试创建账号也会生成完整基础资料和互动样例。低粉丝冷启动样例使用4条历史内容，避免为了补数据意外突破5条有效内容的阶段边界。
