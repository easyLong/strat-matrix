核查日期：2026-10-28。代码基线：`8891ea4`。对象为当前实际可访问的前端页面、复用详情、弹窗和公共交互。

- 静态核查：路由、应用外壳、三个一级页面、复用策划详情、营销任务详情、选题详情、替换选题、配置历史、导出、内容流水、标签配置、分页和横向滚动组件。

- 异常演练：浏览器拦截并模拟数据库不可用和营销提交 422 校验响应，没有将模拟提交发给服务端。

正常页面巡检记录了 23 个页面或交互观察点，没有发现浏览器 JavaScript 未捕获异常；另外单独复核了未修改配置却可保存的现象，并验证了 3 个异常场景。真实写操作的事务结果、外部系统回调、所有屏幕尺寸及逐像素视觉效果不属于这次只读验收。

## AI策划配置

### 只读展示和编辑字段

默认只读总览，顶部按钮依次为“编辑配置”“历史配置”。配置按以下顺序展示：

| 区块 | 字段或列表 | 展示及编辑规则 |
| --- | --- | --- |
| 内容策划配置 | 每周策划日 | 周一至周日多选，至少保留一天，保存按星期升序 |
| 内容策划配置 | 自动策划调度时间 | 星期单选、时分输入 |
| 内容策划配置 | 营销内容周上限 | 非负整数，单位为条 / 营销账号 / 周 |
| 内容策划配置 | 热点选题占比 | 0 至 100 的整数百分比 |
| 策划规则配置 | 生命周期阶段判定 | 稳定经营期、转化放大期、转化试探期、流量增长期、冷启动期 |
| 策划规则配置 | 阶段经营目标 | 冷启动期、流量增长期、转化试探期、转化放大期、稳定经营期；流量、转化及编辑态合计 |
| 策划规则配置 | 滚动统计窗口 | 1 至 100 的整数，单位篇 |
| 策划规则配置 | 选题标签配置 | T1 至 T5 标签页及 T6 悬浮说明 |

阶段经营目标各项为非负整数，每阶段流量与转化之和须为 100%。四个非兜底阶段至少一个条件，每个阈值为非负整数；第五阶段须为无条件兜底。

生命周期指标为粉丝数、有效内容数、滚动篇均互动数；比较符为 `<、≤、≥、>、=`。编辑态四个阶段直接展开，条件组之间显示“或”，组内后续条件显示“且”。“添加且条件”增加本组条件，“添加或条件组”增加新组；删除条件不会删空最后一个条件。当前仍是比较符加单值，并非统一起止范围控件。

默认备用配置为周一、三、五策划，周二 22:00 调度，营销周上限 1、热点 20%、窗口 10 篇；这是前端连接失败时的本地初始值，不能作为数据库当前生效值。冷启动文字根据流量增长期边界派生。

### 配置按钮交互

| 按钮或动作 | 条件 | 结果 |
| --- | --- | --- |
| 编辑配置 | 数据库可用，非忙碌、非加载 | 开启整页编辑，展开阶段条件 |
| 恢复当前配置 | 编辑中且非忙碌 | 重置经营配置草稿；**不重置标签草稿，无二次确认** |
| 取消编辑 | 编辑中 | 无论是否改动都弹出“取消编辑”确认框 |
| 继续编辑 | 确认框右侧红色重点按钮 | 关闭确认框，保留草稿 |
| 确认取消 | 确认框左侧普通按钮 | 经营配置、标签回到各自基线，退出编辑 |
| 保存配置 | 草稿有变化，经营配置和规则均合法、数据库可用 | 先保存经营配置，再保存变动标签，完成后退出编辑 |
| 编辑中点其它路由 | 仅有未保存变化时阻挡 | 弹“离开策划配置？”；右侧继续编辑，左侧放弃并离开 |
| 编辑中浏览器刷新或关闭 | 有未保存变化 | 使用浏览器原生离开提示，这是 `beforeunload` 行为 |

保存请求携带预期版本。标签保存另携带标签版本；经营配置和标签是两个顺序请求，当前不是同一原子事务。

配置每 10 秒同步一次，窗口重新获焦或从后台恢复也检查；页面隐藏、加载或保存中暂停。只读时发现远端新版本自动应用，编辑或有差异时保留草稿并显示“配置已在其它位置更新，当前编辑内容已保留”。标签字典没有同等轮询机制。

### 选题标签配置

| 区域 | 字段与操作 | 排序或限制 |
| --- | --- | --- |
| T1 业务属性 | 营销属性及值 | 固定只读，即使整页编辑也不提供改名停用 |
| T2 经营作用 | 经营作用及值 | 固定只读 |
| T3 内容主题 | 分类、叶子标签、分类内新增、底部新增分类 | 默认进入 T3；保持数据原始顺序 |
| T4 目标客群 | 同上 | 分类可折叠 |
| T5 使用场景 | 同上 | 分类可折叠 |
| T6 用户需求 | 悬浮说明“模型生成一条核心需求，可在选题详情查看。” | 不是可编辑标签页 |
| 启用分类或标签 | 点击后显示“改名、停用” | 浮层不重复展示标签值，不带无意义的删除项 |
| 停用分类或标签 | 底部“已停用标签”折叠区 | 点击仅有“启用”；父分类停用时叶子不能直接操作 |
| 待归类 | 当前配置列表隐藏 | 历史数据仍可能保留引用 |

名称去首尾空格，长度 1 至 80 字；同一维度内同种节点不允许重名，包括停用节点。至少保留一个启用分类和标签。改名、启停和新增先作用于草稿，整页保存后持久化；浮层点外部或 Esc 关闭，改名回车提交，关闭后尽量返回原标签焦点。

### 历史配置

列表列顺序：**版本 → 生成时间 → 配置摘要 → 操作人 → 操作**。无分页和列排序按钮，直接采用接口版本顺序；以当前加载列表位置显示连续 V1、V2 等编号，首条标记当前。

“查看详情”打开抽屉，展示与前一条已加载版本的差异及完整经营配置；生命周期和经营目标一阶段一行。首版提示无更早版本，相同配置提示内容相同。当前抽屉没有标签体系历史详情。

当前版本无恢复按钮；其它版本“恢复此版本”二次确认，恢复后创建新版本而非删除新版本。确认框右侧为红色“确认恢复”，左侧“返回查看”。详情右上角、底部关闭、点击遮罩均可关闭。

## 人工策划

### 策划任务列表

| 列顺序 | 字段 | 显示和交互 |
| --- | --- | --- |
| 1 | 批次 | 上名称，下批次号；表头气泡“名称+批次号”，内容本身无跳转 |
| 2 | 投放日期 | 营销无日期显示“—” |
| 3 | 账号数 | 普通任务为计划账号数；新营销分配任务显示“待分配” |
| 4 | 选题数 | 服务端返回数量 |
| 5 | 策划状态 | 使用 planning_status，其次 status |
| 6 | 内容状态 | 状态与紧凑进度，例如“生成中(0/2)” |
| 7 | 创建人 | 缺失为“—” |
| 8 | 发起时间 | 秒级业务时间 |
| 9 | 更新时间 | 秒级业务时间 |
| 10 | 操作 | 查看策划、查看内容流水或“—” |

当前**没有完成数、失败数列，也没有筛选区**。按普通任务与营销任务创建时间合并倒序；没有列头点击排序。初始每页 10，可选 20、50；初始只分别读取两类接口最近 20 条，分页不代表全库历史。

“新建人工策划”受数据库可用性限制。“查看策划”有正式批次时跳到复用批次详情，无批次营销需求打开营销详情；非营销无批次时没有查看入口。“查看内容流水”只要有批次就显示，不判断生产是否已经开始。

任务存在执行或生产中的状态时每 3 秒重新读取列表；待分配且无批次的营销任务本身不会触发该轮询。列表轮询在创建任务期间仍可能运行。

### 创建策划

| 字段 | 默认 | 校验及变化 |
| --- | --- | --- |
| 任务名称 | 空 | 必填，前端输入上限 120 字，提交去首尾空格 |
| 选题类型 | 非营销 | 营销 / 非营销 |
| 投放日期 | 空 | 仅非营销必填，无“只能未来日期”的前端限制 |

营销三步：**创建策划 → 选择选题 → 确认策划**。非营销四步：**创建策划 → 选择账号 → 选择选题 → 确认策划**。

切换类型清空已选账号、选题、计划数量和导入统计，选题库默认类型随之变化。步骤条仅允许回到之前步骤，提交中禁用步骤切换；已填写数据通常保留，但“新建”没有清空所有账号筛选值。

顶部“返回任务列表”直接退出创建；当前没有草稿存储、未保存离开确认或提交中拦截。离开路由或刷新后创建过程丢失。

### 非营销选择账号

默认方式为维度筛选且条件展开；切换模板导入后展示下载和上传区。计划账号数量标签及输入同行，放于选择方式下面。

筛选顺序：**生命周期 → 粉丝量起止 → 账号类型 → 属主组织 → 平台 → 账号 ID 或昵称 → 属主 UM 号 → 查询**。没有业务线和地域。姓名、ID、别名及 UM 为不区分大小写的包含查询；组织、平台、类型、阶段为精确匹配。

查询之前修改字段和计划数量不改变实际筛选结果；点击查询后应用筛选，并按粉丝量倒序抽取至计划数量。候选不足时选取实际可用数量，保留计划与实际差额，不再直接报抽取失败。非法计划数量查询时会清空当前选择，保存时再报校验信息。

账号表列顺序：**选择框 → 账号类型 → 属主 UM 号 → 账号昵称 → 账号 ID → 属主组织 → 平台 → 生命周期 → 粉丝数**。

- 排序：已选最前；同组选粉丝数倒序，缺失按 -1，再按中文账号名称升序。
- 行点击或键盘 Enter、空格可切换勾选；表头全选是当前筛选下可用账号的跨页全选。
- 已完成所选日期人工策划的账号置灰不可选，悬浮显示“日期 已手动策划，不可重复选择”，不增加规划状态列。
- 顶部计数展示符合条件或导入识别、可策划、当日已策划、已选数量。
- 分页默认 20，可选 50、100；保留跨页选择。已选账号可因置顶继续出现在新筛选之外。
- 保存重新查询当日资格，冻结整块 fieldset，列表回第一页并滚到顶部；保存条展示计划数、实际数及未达或超出计划差额。
- 返回调整解除冻结；下一步保留保存值，滚到步骤条。数量差额目前只是展示，不弹窗，也不自动修改计划数量。

### 账号模板导入

模板是 CSV，下载表头“UM号,账号ID”，支持 UTF-8，出现解码替换符时尝试 GB18030。单次最多 1000 个非空数据行，不支持 Excel 工作簿解析。

| 输入情况 | 当前结果 |
| --- | --- |
| 有账号 ID | 精确匹配，忽略大小写与首尾空格 |
| 只有 UM 号 | 必须只对应一个账号 |
| UM 号对应多个账号 | 未识别，提示补充账号 ID |
| 两者都填 | 必须指向同一账号 |
| 同一账号重复出现 | 只保留首次记录，重复行另统计 |
| 所选投放日期已有正式人工策划 | 计入已投放异常，不勾选 |
| 标识不存在或不对应 | 计入未识别异常 |
| 空文件、只有表头、引号不闭合、超行数 | 页面顶部显示明确错误 |

计划数量按非空数据行数计，包含重复和异常行。上传后显示“导入 / 成功 / 重复 / 异常”，成功数当前等于可勾选且去重后的账号数，异常数为未识别加已投放。

有问题自动弹“部分账号识别异常”，下方区分“未能识别账号”“已投放账号”和重复行号；下载异常 CSV，或点知道了、右上角、遮罩关闭；成功账号可继续。顶部导入成功数不会随之后手动勾选变化，动态已选数另行显示。

### 选择选题

| 属性 | 营销任务 | 非营销任务 |
| --- | --- | --- |
| 选择形式 | 单选框，点击新行替换原选题 | 勾选，最多 100 个不同 ID |
| 已选区 | 无左侧已选栏，全宽列表 | 左侧按加入顺序展示 ID、标题、大纲、二级分类；可 × 移除 |
| 默认类型 | 营销，可切换非营销 | 固定非营销，类型控件禁用 |
| 分配数量 | 选中后列表下方显示，必填 1 至 1000 | 无 |
| 数量计数 | 已选 0 或 1 个 | 已选实际个数，不显示“/100”总量 |

筛选默认展开，顺序：**选题 ID → 选题标题 → 选题类型 → 选题二级分类 → 关联产品 → 关联活动 → 关联属地热点 → 清空筛选 / 查询**。没有内容主题、目标客群、使用场景筛选。ID 为文本输入精确匹配，标题为文本模糊匹配，其余下拉精确匹配。

“清空筛选”只清空输入草稿，仍需点击查询才影响结果；不清空已选。查询和换页保留已选，右侧列表不主动把已选置顶。

列表列顺序：**选择 → 选题 ID → 选题标题 → 选题大纲 → 选题类型 → 选题二级分类 → 关联产品 → 关联活动 → 关联属地热点 → 有效期**。按选题接口顺序，当前服务端为主键升序；无排序按钮。每页默认 20，可选 50、100。

标题用自定义悬浮气泡，不是详情链接；点击标题气泡不会同时勾选。大纲省略后用原生 title 显示全文，左侧已选卡片 title 展示完整选题资料。有效期显示起止日期，缺失为不限。

保存时检查选题数及营销分配数量；将已选选择锁定并回到列表第一页、顶部，保存条提供返回调整和下一步。**筛选输入未整体冻结**，仍可查询另一列表。营销分配数量单独冻结。

### 确认策划及提交

确认页摘要列：任务名称、选题类型，以及营销的分配数量或非营销的“实际账号数 · 计划账号数”。非营销投放日期当前未在确认摘要再次显示。

非营销左侧账号表源码字段为“账号名称、属主 UM 号、账号类型”；实际运行被全局增强脚本改成“账号昵称、账号ID、账号类型”，见问题 F-02。右侧及营销全宽选题表字段为“选题 ID、选题标题、选题大纲、选题二级分类”。各自每页默认 10，可选 20、50，表区可滚动，长文字气泡查看。

固定底部操作为“上一步 / 提交人工策划”。点击上一步回到选题未保存态，保留已选；切换步骤滚到步骤条。提交按钮仅在数据库可用、非忙碌及各模式输入有效时启用，提交时显示“正在提交…”。

- 营销：调用营销创建接口，只传任务名称、单个选题 ID、总分配数量、UUID；成功回任务列表，提示“营销策划已提交”。没有真实调用外部系统分配。
- 非营销：再次检查所选日期可用账号；有变化则退回选择账号并提示。通过预览接口后提交预览，再回任务列表并提示“手动策划已提交，当前状态：生成中”。
- 营销有提交 UUID 幂等保护；非营销每次提交先生成新预览，丢失提交响应时没有同等前端任务标识恢复流程。
- 资格不符且错误包含“不具备所选营销选题资格”时，再弹“选题资格不匹配”，可知道了或返回修改选择。

### 营销任务详情

从列表查看无正式批次的营销需求仍使用右侧抽屉，标题“营销策划详情”；这是历史需求查看，与已恢复的创建确认步骤不同。

未分配的新任务展示分配数量、账号分配“待外部系统”和状态；没有账号表。有账号的历史任务展示账号数、每账号条数、总生产数量，账号表列为昵称、ID、属主 UM 号、账号类型，默认每页 20。

选题表列为 ID、标题、大纲、二级分类，无额外排序与分页。当前详情仅加载一次，无状态轮询；返回任务列表、遮罩、Esc 均可关闭。

## 策划结果

### 账号列表

筛选默认展开；顺序与非营销选择账号相同：**生命周期、粉丝量起止、账号类型、属主组织、平台、账号 ID 或昵称、属主 UM 号、查询**。无日期、周期、地域、业务线筛选。输入不自动查，点查询后更新列表和分页。

列顺序：**账号名称及 ID → 属主 UM 号 → 属主组织 → 账号类型 → 平台 → 生命周期 → 粉丝量 → 账号状态 → 策划结果**。账号本身无链接；末列“查看策划”进入账号详情。

默认采用服务端“最近批次创建时间倒序 → 账号名 → 账号 ID”顺序。每页 20，可选 10、50；无列排序。账号清单来自参与过策划的账号摘要，基本信息来自另外加载的账号目录，包括停用账号；不是全量未参与过策划的账号。

页面顶部“导出报表”取**全部筛选命中账号**，而非当前分页。导出弹窗必填起止日期；成功生成 CSV 后关闭。底部固定横向滚动条与账号表同步，字段超宽时显示。

### 时间列表

筛选默认展开，字段为开始时间、结束时间、批次号或批次 ID、查询。时间按周期起止与输入区间是否相交判断，不按实际每条策划的投放日期裁剪；批次 ID 精确匹配，批次号包含匹配，不匹配批次名称。

| 列顺序 | 字段 | 统计含义 |
| --- | --- | --- |
| 1 | 策划周期 | 周一至周日的起止日期 |
| 2 | 批次构成 | 当前命中批次数 |
| 3 | AI 自动策划 | 批次数、各批次账号数之和 |
| 4 | 人工策划 | 批次数、各批次账号数之和 |
| 5 | 账号数 | 全部命中批次账号数相加，不跨批次去重 |
| 6 | 完成数 | 各批次完成账号数相加 |
| 7 | 失败数 | 各批次失败账号数相加 |
| 8 | 最后更新 | 命中批次最新更新时间，缺失退创建时间 |
| 9 | 操作 | 查看批次、查看策划、导出报表、查看失败详情 |

按周开始日期倒序，默认每页 20 周期，可选 10、50。完成数大于 0 用成功色、失败数大于 0 用危险色，0 弱化。没有前端持续刷新。

行内批次按**自动优先 → 同种方式最近更新时间倒序**；不是全部批次按创建时间统一倒序。字段：批次名称及号、策划方式、批次周期、账号数、完成数、失败数、选题数、策划状态、内容进度、更新时间、操作。操作为查看策划和导出报表；行内批次表没有分页。

批次内容进度实际显示状态与“完成生产账号 / 总账号”，标题仍为“内容进度”。它只接收完成数和总数：0 为待生成，大于 0 未满为生成中，完成数达到总数为已完成，不读取真实运行或失败标记。

### 失败详情

仅失败数大于 0 才出现按钮，且在操作区最后。右侧抽屉展示：账号名称及 ID、属主 UM 号、批次号、失败原因。无分页和列排序，采用接口顺序。

“导出失败 UM 号”在有 UM 的记录时可用，导出字段为属主UM号、账号名称、账号ID、批次号、失败原因；跳过没有 UM 的行，不按 UM 去重。同账号在多个批次失败可有多行，顶部“失败账号 X 个”实际是记录条数，可能包含批次级异常。

查询按整个周期执行，当前不传列表中的批次搜索范围。抽屉展示“以下账号未完成本周期策划，可转人工策划补充。”，是提示文字，没有直接带账号跳转人工策划的按钮。关闭方式为右上角或遮罩，未实现独立 Esc、焦点圈定。

同一选题在同一分类下只计一次；同一 ID 在历史不同版本具有不同分类时，可分别计入不同分类，分类之和不保证等于总去重选题数。热点未定题没有 ID，不计入使用选题。

周期和批次详情按中文账号名升序排列；每账号内按投放日期升序、明细 ID 升序，同一天多条按此顺序展示。账号列表分页默认 20，可选 10、50；点展开可同时保留多个账号展开，各账号内周按新到旧排列。

账号头部显示名称、认证类型、经营阶段，以及带明确前缀的账号 ID、属主 UM 号、所属组织、平台、人设；组织使用原 organization 文本，没有前端解析或强制到二级分行的逻辑。

卡片显示策划方式、内容状态、标题、二级分类；周期及批次账号卡还显示普通 / 营销 / 热点类型，周期卡显示批次号。无计划日期显示“暂无计划”。周历超宽可横向滚动，滚动条在本周容器下方，不是整个页面统一固定滚动条。

周期详情内“查看批次”可展开表：**批次、策划方式、账号数、策划状态、更新时间、操作**。批次名称上、批次号下；采用传入顺序。超过 10 批次才显示分页，默认 10，可选 20、50；按详情账号或分类筛选不会改变该批次表。

周期、批次明细在存在待生产或生产中记录时每 3 秒静默刷新；账号详情的历史数据不在这一轮询判断内。账号目录读取失败会静默降级，元信息可能为“—”；明细读取失败直接用错误条替代内容。

### 单条计划详情

日历卡片点击打开同一个复用抽屉。当前实际只有三块：

| 区块 | 字段及交互 |
| --- | --- |
| 策划信息 | 投放日期及星期、批次周期、批次编号、策划方式、经营阶段、经营作用、内容状态 |
| 选题信息 | 二级分类、选题 ID、标题、大纲、有效期、T1 至 T6 标签；有资格时显示替换选题 |
| 操作记录 | 策划结果生成及选题调整，包含动作、时间、说明、操作方 |

没有独立账号信息块，账号名称只在抽屉标题出现。周期和批次父页有完整账号头，账号详情父页只有账号名称及 ID 标签，信息完整性不同。

选题信息优先采用当前选题目录或详情查询返回值，缺失时使用策划明细字段兜底。操作记录只组合批次创建记录与选题调整记录，不包含内容生产、审核等完整业务事件。按操作时间倒序；调整接口默认最近 50 条。

### 替换选题

入口前提是后端 `allow_replace=true`、已有选题 ID，且前端映射不处于生产中；后端还检查支持的策划方式、槽位 ID、结果版本一致、未发布及非生产中。已生产但未发布的内容当前仍可能允许替换，这一边界须由业务确认。

进入替换时清空本次候选单选、原因和筛选输入，筛选默认折叠。字段为选题 ID、标题、选题类型、二级分类、关联产品、关联活动、关联属地热点；点击查询生效，清空筛选只清输入。

候选采用接口顺序，不做前端排序及分页；单选候选，标题可进一步打开选题详情抽屉，候选同时显示 ID、分类、有效截止日和大纲。

替换原因可选：原选题与账号不匹配、选题重复、内容方向不合适、业务临时调整、其他。确认按钮在有单选值且非保存中时可用；提交携带明细 ID、新选题 ID、预期结果版本、原因。

成功更新父页记录、选题显示及调整记录，恢复先前计划详情与滚动位置；失败显示错误并保留选择。关闭 × 或遮罩会关闭整个计划详情，目前没有独立“取消替换并返回原详情”的按钮。

### 选题详情

从替换候选标题可打开选题详情抽屉。先用已有选题展示，再读取完整详情；字段为 ID、标题、二级分类、营销 / 非营销、打标状态、大纲、有效期和标签。

标签展示：T1 业务属性及适用范围、T2 经营作用、T3 主主题和关联主题的完整路径、T4 目标客群路径、T5 使用场景路径、T6 核心用户需求。已打标但确无关联项显示“无”或“未限定”，未识别显示“未识别”。

加载失败保留已有选题内容并显示错误；没有完整来源时有效期仍回退“不限”。Esc、右上角、遮罩可关闭，焦点返回原按钮。

### 内容流水

内容流水抽屉按接口原顺序展示，无前端分页、搜索和排序控件。每条字段为选题标题、状态、账号名、投放日期、生产任务 ID、受理时间、完成时间、错误原因；本地模拟任务附模拟标记，有正文时可折叠“查看内容”。

状态 `accepted/processing` 映射生产中，`completed` 已完成，`failed` 生产失败，未知值直接显示原值。每 3 秒查询一次，成功清错误；任务 ID 与状态指纹变化时通知父页刷新。右上角、遮罩、Esc 关闭，支持 Tab 圈定和关闭后焦点恢复。

### 明细导出

导出固定 14 列：**账号ID、账号昵称、投放日期、批次号、策划方式、选题ID、选题标题、选题大纲、选题二级分类、内容状态、最新操作、操作人、操作时间、操作说明**。

账号入口要求有效起止日期，逐账号查询后在前端截取日期并精确保留目标账号；时间或批次入口使用传入批次，无日期弹窗字段。导出全部命中明细而非当前分页，顺序保持账号或批次传入顺序及接口内部顺序，没有统一二次排序。

每条策划再查询调整记录，取最新调整或回退策划结果生成信息；任一请求失败则整体导出失败。并行请求最多 8 个。账号记录达到 5000 或批次数达到 5000 时阻止导出并提示缩小范围，防止直接导出截断结果。

CSV 使用 UTF-8 BOM、字段引号转义，并对公式型首字符做前缀处理。弹窗“取消”及遮罩在导出中禁用，确认按钮显示导出中；成功下载并关闭，无成功 Toast。失败停留弹窗；重新打开时原错误和日期仍保留，直到再次确认重置错误。

所有常规表格当前均无可点击列头排序。公共分页提供上一页、页码、下一页和每页条数，不提供任意页跳转输入；变更每页条数回第一页，边界禁用，空列表有时仍显示第 1 页。

| 范围 | 当前可见值或计算方式 | 备注 |
