# 前端 JavaScript 与选项式 API 迁移

日期：2026-11-09。

## 范围

按本轮确认，完成 **TypeScript → JavaScript、组合式 API → Vue 2 原生选项式 API**。39 个组件的模板、样式及业务字段保持原样；Java/Python 业务接口和数据库结构不变。

| 项目 | 当前实现 |
| --- | --- |
| 语言 | `.js` 模块及普通 `<script>`，删除 TypeScript 源文件和 tsconfig |
| 组件 | `data`、`computed`、`methods`、`created`、原生缓存及销毁生命周期 |
| 运行依赖 | Vue 2.6.14、Vuex 3.6.0、Axios 1.8.2、Element UI 2.15.13、Vue Router 3.6.5 |
| 删除依赖 | `@vue/composition-api`、`typescript`、`vue-tsc`、直接依赖的 `@types/node` |
| 行外构建 | 保留 Vite 4.5.14；`npm run build` 不再执行 TS 类型检查 |
| 行内构建 | 复用宿主 Vue CLI/webpack，不复制本项目行外启动壳 |

本轮没有升级或替换 UI 组件库，也没有迁移到 Vue CLI 4/webpack 4。现场仍需验证宿主 Babel、Vue 模板编译器对现有 JS 表达式的支持，以及样式和弹层层级。

## 代码落点

| 路径 | 职责 |
| --- | --- |
| `frontend/src/views/`、`components/` | 三页面及共用组件，均使用选项式 API |
| `src/models/accountSelection.js` | 账号筛选、计划数量、跨页勾选、UM/账号 ID 导入及可策划校验 |
| `src/models/topicSelection.js` | 选题筛选、营销单选/非营销多选、有效期、冻结和恢复 |
| `src/models/workspaceTabs.js` | 行外页签及关闭草稿确认；宿主使用自身页签机制 |
| `src/services/pageActivity.js` | 绑定原生挂载、激活、停用、销毁事件，统一启停轮询和监听 |
| `src/services/asyncPage.js` | 请求归属、取消旧请求、停用暂停、销毁后禁止回写 |
| `src/compat/router.js` | 宿主路径前缀与导航失败处理，无组合式 API |
| `src/integration.js` | 宿主 HTTP、Vuex、权限、路由及错误适配入口 |
| `vite.config.js`、`tooling/serverOptions.js` | 行外构建与 Java 代理配置 |

共享选择模型使用原生 Vue 2 实例的选项对象维护状态，不再传递 `ref.value`。子组件通过原生 computed 的 getter/setter 访问状态；DOM 引用由实际渲染它的组件在 mounted/updated 时登记，销毁时清理。父页面销毁会销毁对应模型和观察器。

页签切换保留草稿及分页，关闭页签移除缓存；隐藏页停止监听和定时器，恢复后再启动。接口查询继续手动点击，数据有效期及模板异常处理口径保持不变。

## 驻场迁入

1. 复制 `src` 中业务视图、组件、models、services、compat、ui、api、host、styles、data 及共享 JS/CSS 到宿主指定供应商目录。
2. 使用 `integration.js` 接入现有 Axios、Vuex、权限码、菜单路径和 Java API 前缀，具体示例见 [Vue 2 接入说明](../frontend/VUE2_INTEGRATION.md)。
3. 保留宿主现有启动文件、package/lock、Vue CLI/webpack 和基础组件注册，避免额外创建 Vue 应用或安装组合式 API 插件。
4. 在真实宿主构建及浏览器中确认模板表达式、样式隔离、页签缓存、退出草稿、下载及权限。行外测试不能替代这一步。

代码包生成器已同步使用 `vite.config.js`，不再读取已删除的 TS 配置和入口。
