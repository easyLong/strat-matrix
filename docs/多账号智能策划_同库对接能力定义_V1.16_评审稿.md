# 多账号智能策划同库对接能力定义

V1.16 评审稿｜2026-10-24

## 一、文档范围与对接方式

本稿以 V1.13 已确认字段、2026 年 10 月 21 日会议记录及本轮逐项确认的口径为依据，整理行内与策划侧需要共同确认的数据和可调用能力。打标测试沿用 V1.14 的精简输入结构。

本稿是对接定义，不表示代码、表结构及行内实际字段已经完成适配。尚未确认的规则集中列于文末。

本版修正 OP 的对外边界：行内以已有账号 ID、选题 ID 查询策划侧结果，不要求调用方预先掌握槽位 ID、策划版本或生产任务 ID。营销日期计算及更新保留在 IF-04 的内部衔接流程中，不再单列为 OP。

| 项目 | 约定 |
| --- | --- |
| 基础数据 | 账号、选题、营销内容直接读取行内现有表，通过约定的方法返回数据 |
| 策划扩展数据 | 标签、画像、向量及内部处理记录由策划侧维护，通过账号 ID、选题 ID 等关联 |
| 策划结果 | 策划侧落表；生产扫描器按约定读取明细，行内业务功能通过 OP-01 按账号查询策划结果 |
| 交互方式 | 同库查询、同库方法调用及约定表的读写，不将跨系统 HTTP 同步和全量基础数据复制作为本轮方案 |
| 字段名称 | 行内原始字段使用中文业务名称，实际名称由行内表结构映射；策划侧定义的字段可标注英文名称 |
| 时间 | 统一采用北京时间；日期表示为 YYYY-MM-DD，时间表示为 YYYY-MM-DD HH:mm:ss |
| 查询时间范围 | 开始时间包含、结束时间不包含，即开始时间 ≤ 数据更新时间 < 结束时间 |

## 二、能力总览

| 编号 | 名称 | 提供及使用边界 | 交付内容 |
| --- | --- | --- | --- |
| IF-01 | 账号信息查询能力 | 行内提供，策划侧使用 | 可参与策划账号的基础信息、人设及历史互动明细 |
| IF-02 | 选题信息查询能力 | 行内提供，策划侧使用 | 普通、热点选题详情，统一分页查询 |
| IF-03 | 可排期营销内容查询能力 | 行内提供，策划侧使用 | 指定账号名下审核通过、未分配日期的营销内容 |
| IF-04 | 内容生产与营销内容衔接能力 | 双方共同约定；行内负责扫描及内容处理，策划侧负责策划和日期 | 普通／热点生产衔接、营销内容填充与排期衔接 |
| OP-01 | 账号策划详情查询能力 | 策划侧提供，行内调用 | 按账号 ID 查询自动及人工策划结果、关联选题／内容和处理状态 |
| OP-02 | 选题使用次数查询能力 | 策划侧提供，行内调用 | 指定选题在统计范围内的正式使用次数 |
| OP-03 | 选题标签查询能力 | 策划侧提供，行内调用 | 已保存的正式标签及标签处理状态 |
| OP-04 | 选题批量打标效果测试能力 | 策划侧提供，行内或运营测试入口调用 | 本次测试的逐条标签结果 |

IF-04 是同库衔接约定，不是独立的主动提交生产 HTTP 接口。当前不另设 IF-05。

行内业务调用以账号 ID、选题 ID 等已有标识为入口。OP-01 通过同库方法提供账号策划结果，不要求增加跨系统 HTTP 调用；生产扫描器仍可直接读取约定结果表。页面内部查询、扫描器内部定位和对外结果查询分别按各自职责实现。

## 三、IF-01 账号信息查询能力

### 1. 基本说明

| 项目 | 说明 |
| --- | --- |
| 数据提供方 | 行内 |
| 数据使用方 | 策划侧 |
| 获取方式 | 通过查询方法直接读取行内现有账号及关联表 |
| 返回范围 | 仅可参与策划的账号 |
| 关联标识 | 账号 ID |

### 2. 查询参数

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| 页码 | 是 | 从第 1 页开始 |
| 每页账号数 | 是 | 每页获取的账号数量，上限由双方确认 |
| 更新开始时间 | 否 | 获取该时间及之后更新的账号 |
| 更新结束时间 | 否 | 获取该时间之前更新的账号 |

不传时间范围时，分页获取全部可参与策划的账号。仅传一端时，仅限制对应边界。同一轮分页保持查询条件及每页账号数不变。

### 3. 分页返回

| 字段 | 说明 |
| --- | --- |
| 账号总数 | 按账号状态及时间条件过滤后的账号总数 |
| 当前页码 | 当前返回页码 |
| 每页账号数 | 本次采用的分页大小 |
| 账号列表 | 当前页账号，每个账号包含以下基础、人设及互动信息 |

### 4. 账号基础信息

| 字段 | 说明 |
| --- | --- |
| 账号 ID | 账号唯一标识 |
| 账号昵称 | 账号当前昵称 |
| 属主 UM 号 | 账号所属人员的 UM 号 |
| 属主组织 | 账号所属组织，包含所属分行信息 |
| 平台 | 账号所属平台 |
| 账号类型 | 认证／非认证 |
| 账号状态 | 本账号是否可参与策划：是／否；本查询仅返回“是”的账号 |
| 粉丝量 | 账号当前粉丝数量 |
| 账号信息更新时间 | 账号基础信息或人设信息最后更新时间，应覆盖关联表中的信息变化 |

### 5. 账号人设信息

| 字段 | 说明 |
| --- | --- |
| 账号人设 | 车圈达人等现有人设信息 |
| 性别 | 行内现有性别信息 |
| 兴趣爱好 | 行内现有兴趣爱好信息 |
| 表达风格 | 行内现有内容表达风格信息 |

### 6. 历史内容及互动明细

每个账号提供近三个月已发布内容及互动数据，每条包含：

| 字段 | 说明 |
| --- | --- |
| 内容 ID | 已发布内容唯一标识 |
| 账号 ID | 内容所属账号 |
| 发布时间 | 实际发布时间 |
| 内容标题 | 已发布内容标题 |
| 点赞数 | 累计点赞数量 |
| 收藏数 | 累计收藏数量，平台支持时提供 |
| 评论数 | 累计评论数量 |
| 互动数据更新时间 | 该条内容互动数据最后更新时间 |

### 7. 查询口径

- 一个账号计为一条，关联明细不得造成账号重复；按账号 ID 固定排序。
- 不可参与策划的账号直接过滤，不返回；分页总数同样按过滤后的结果统计。
- 无匹配记录或超出末页时，返回空账号列表。
- 互动变化是否同时体现在账号信息更新时间中，需行内确认，不能默认两者等价。
- 不包含业务线、地域、分享数及历史内容关联选题信息。
- 生命周期、算法自定义字段及画像处理状态由策划侧维护。画像更新采用关联字段 MD5 变化判断，不要求行内提供画像增量状态。

## 四、IF-02 选题信息查询能力

### 1. 基本说明

| 项目 | 说明 |
| --- | --- |
| 数据提供方 | 行内 |
| 数据使用方 | 策划侧 |
| 获取方式 | 通过查询方法直接读取行内现有选题表 |
| 数据范围 | 普通选题、热点选题 |
| 关联标识 | 选题 ID |

普通与热点统一查询，通过“选题来源”区分。内容分类沿用行内实际枚举，不固定写为 12 种。

### 2. 查询参数

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| 页码 | 是 | 从第 1 页开始 |
| 每页选题数 | 是 | 每页获取的选题数量，上限由双方确认 |
| 更新开始时间 | 是 | 获取该时间及之后更新的选题 |
| 更新结束时间 | 是 | 获取该时间之前更新的选题 |
| 选题来源 | 否 | 普通／热点；不传则查询两类 |

时间范围依据选题更新时间，不是选题有效期或投放日期。同一轮分页保持查询条件及每页选题数不变。

### 3. 分页返回

| 字段 | 说明 |
| --- | --- |
| 选题总数 | 符合本次查询条件的选题总数 |
| 当前页码 | 当前返回页码 |
| 每页选题数 | 本次采用的分页大小 |
| 选题列表 | 当前页选题，每条包含以下信息 |

### 4. 选题信息

| 字段 | 说明 |
| --- | --- |
| 选题 ID | 选题唯一标识 |
| 选题来源 | 普通／热点 |
| 选题标题 | 选题标题 |
| 选题大纲 | 选题大纲或核心内容 |
| 内容类型 | 行内现有内容分类，具体枚举由行内提供 |
| 热度 | 行内提供的选题热度；实际字段及可提供情况需核对 |
| 选题状态 | 行内现有的有效、失效等可用状态 |
| 有效开始时间 | 有效期起点，为空表示不限制起点 |
| 有效结束时间 | 有效期终点，为空表示不限制终点 |
| 选题更新时间 | 最后更新时间，也是查询时间范围的判断依据 |

### 5. 查询口径

- 按选题分页，普通与热点合并后统一计算总数、排序及分页。
- 以选题 ID 唯一标识选题，按选题 ID 固定排序。
- 无匹配记录或超出末页时返回空列表。
- 标题、大纲、来源、内容类型、热度、状态及有效期等变化应更新选题更新时间。
- 标签、画像、向量及内部处理记录由策划侧维护，不要求行内提供。

## 五、IF-03 可排期营销内容查询能力

### 1. 基本说明

| 项目 | 说明 |
| --- | --- |
| 数据提供方 | 行内 |
| 数据使用方 | 策划侧 |
| 获取方式 | 通过查询方法直接读取行内现有营销内容表 |
| 数据范围 | 指定账号名下、审核通过且尚未分配投放日期的营销内容 |
| 关联标识 | 内容 ID、绑定账号 ID |

本能力获取已经生成并审核通过的营销内容，不是营销选题，也不触发重新生产。

### 2. 查询参数

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| 账号 ID | 是 | 查询该账号名下可排期的营销内容 |
| 页码 | 是 | 从第 1 页开始 |
| 每页内容数 | 是 | 每页获取的内容数量，上限由双方确认 |

不设置更新时间范围，不限制生产月份或生产批次。同一轮分页保持账号 ID 及每页内容数不变。

### 3. 分页返回

| 字段 | 说明 |
| --- | --- |
| 内容总数 | 指定账号名下符合条件的营销内容总数 |
| 当前页码 | 当前返回页码 |
| 每页内容数 | 本次采用的分页大小 |
| 内容列表 | 当前页营销内容，每条包含以下信息 |

### 4. 营销内容信息

| 字段 | 说明 |
| --- | --- |
| 内容 ID | 已过审营销内容唯一标识 |
| 绑定账号 ID | 内容所属账号，与查询账号一致 |
| 内容标题 | 已生成的标题 |
| 内容正文 | 已生成的完整正文 |
| 关联产品 | 产品类内容关联的产品信息，具体子字段由行内确认 |
| 关联活动 | 活动类内容关联的活动信息，具体子字段由行内确认 |
| 审核通过时间 | 该条内容审核通过的时间 |

### 5. 查询与选取口径

- 仅返回对应账号、审核通过且没有投放日期的内容。
- 包含符合条件的历史库存，不仅限最新批次或当月内容。
- 多条可用内容按审核通过时间升序选取，先审核通过的优先。分页顺序与选取顺序一致；同一时间下的稳定排序由技术实现补充。
- 一条内容计为一条，关联产品或活动不得造成重复。
- 无匹配记录或超出末页时返回空列表。
- 暂不包含图片列表，不照搬选题大纲、选题热度及选题标签字段。

## 六、IF-04 内容生产与营销内容衔接能力

### 1. 基本说明

| 项目 | 说明 |
| --- | --- |
| 策划数据维护方 | 策划侧 |
| 扫描及内容处理方 | 行内 |
| 投放日期维护方 | 策划侧 |
| 对接方式 | 策划侧落表，行内扫描器读取符合条件的记录 |
| 普通／热点 | 根据已确定选题执行内容生产 |
| 营销 | 关联已过审营销内容，由策划侧安排投放日期 |

### 2. 策划明细主要字段

| 字段 | 说明 |
| --- | --- |
| 槽位 ID（`slot_id`） | 单条策划唯一标识 |
| 策划结果版本（`version`） | 当前策划版本 |
| 批次 ID（`batch_id`） | 所属策划批次 |
| 账号 ID | 明细所属账号 |
| 策划方式（`plan_type`） | 自动策划／人工策划 |
| 槽位类型（`slot_type`） | 普通／营销／热点，用于区分处理流程 |
| 周期开始日期（`cycle_start`） | 所属周期开始日期；尚未确定时可为空 |
| 周期结束日期（`cycle_end`） | 所属周期结束日期；尚未确定时可为空 |
| 投放日期（`publish_date`） | 策划侧维护；人工营销初始为空 |
| 选题 ID | 普通／热点采用的选题；尚未定题及营销明细可为空 |
| 选题来源 | 普通／热点；营销明细不填 |
| 内容类型 | 普通／热点生产采用的行内内容分类 |
| 内容 ID | 行内填充的内容标识；普通／热点的多条生产记录通过关联记录保留 |
| 策划状态（`planning_status`） | 标识策划是否完成 |
| 内容状态（`content_status`） | 策划侧维护的内容处理进展 |

不包含投放时刻字段。普通／热点用选题 ID 唯一标识选题，营销用内容 ID 唯一标识已过审内容，槽位 ID 唯一标识具体策划明细。

### 3. 普通／热点扫描领取条件

同时满足：已完成策划、已确定选题且具备有效选题 ID、内容状态为待生产。

热点空槽尚未定题时，不领取生产。

### 4. 普通／热点处理流程

1. 策划侧完成策划、确定选题，将明细保存为待生产。
2. 行内扫描器领取符合条件的记录。
3. 根据账号 ID、选题 ID、选题来源等关联行内原始数据，组装实际生产参数并调用内容 Agent。
4. 生产链路持续携带槽位关联，保存生产内容记录。
5. 策划侧根据约定的生成、质检／质控及审核规则维护统一内容状态。

同一选题可用于多个账号或多条明细；生产记录必须能关联具体槽位，不能将同一选题的不同生产结果混为一个状态。

### 5. 营销内容两种模式

| 项目 | 自动策划 | 人工策划（营销） |
| --- | --- | --- |
| 明细生成依据 | 周期及策划配置 | 所选账号、每账号指定数量 |
| 初始投放日期 | 策划侧已经确定 | 为空 |
| 初始内容 ID | 为空，等待填充 | 为空，等待填充 |
| 扫描器职责 | 填充内容 ID，衔接日期保存 | 填充内容 ID，调用策划侧排期方法 |
| 日期处理 | 策划侧沿用既定日期 | 策划侧计算、分配并保存日期 |
| 扫描器运行时机 | 周自动策划确定后运行 | 待定义，建议近实时扫描，有符合条件的内容后立即填充 |

人工营销只按账号及每账号指定数量生成明细，不提前提供选题 ID、内容 ID 或投放日期。例如 3 个账号、每账号 2 条，先生成 6 条明细。

营销内容通过 IF-03 获取，先审核通过的优先填充。自动策划保留预定日期，人工策划由策划侧内部排期方法确定日期。该方法负责日期计算及保存，不作为面向行内业务功能的 OP 结果查询接口。已有营销内容不再触发生成、质检或审核。

### 6. 双方职责

| 策划侧 | 行内 |
| --- | --- |
| 创建策划批次和明细 | 实现扫描器及内容处理流程 |
| 普通／热点确定选题和日期 | 关联原始数据并执行生产 |
| 自动策划提前确定日期 | 为营销明细填充内容 ID |
| 人工营销按账号和数量生成明细 | 人工营销填充后调用策划侧排期方法 |
| 实现日期计算、分配、调整及保存方法 | 提供营销内容日期字段及写入所需表结构或方法 |
| 展示统一处理状态 | 提供生成、质检、审核的真实状态及记录关联 |

## 七、策划结果共享与业务查询

行内扫描器直接读取双方约定的策划结果表；行内业务功能通过 OP-01 传入账号 ID 获取账号策划详情。两者使用同一份策划结果，不复制另一套基础数据，不要求业务调用方提供槽位 ID。

策划侧交付结果表结构、关联说明及 OP-01 方法和返回对象。扫描器内部关联用到的槽位 ID、版本等，留在内部衔接约定中。

| 结果分组 | 主要内容 |
| --- | --- |
| 批次信息 | 批次 ID（`batch_id`）、批次名称（`batch_name`）、策划方式（`plan_type`）、策划状态（`planning_status`） |
| 明细信息 | 槽位 ID（`slot_id`）、策划结果版本（`version`）、账号 ID、周期、投放日期（`publish_date`） |
| 普通／热点结果 | 选题 ID、选题来源、内容类型 |
| 营销结果 | 已关联内容 ID、投放日期（`publish_date`） |
| 处理结果 | 内容状态（`content_status`）及生产记录、已有内容的关联信息 |

账号、人设、选题详情和营销正文等原始信息继续关联行内表，不在此另定义一份基础数据。

内容状态计算是策划侧内部规则，不单列 OP。普通／热点需结合生成、质检／质控及人工审核确定完成条件；营销关联已有内容并完成日期保存后即完成本次衔接，不表示已经发布。营销等待状态名称、普通／热点最终状态映射及一槽位多记录的取舍规则待确认。

## 八、OP-01 账号策划详情查询能力

### 1. 基本说明

| 项目 | 说明 |
| --- | --- |
| 能力提供方 | 策划侧 |
| 调用方 | 行内账号页面、业务功能及其他需要查看策划结果的模块 |
| 用途 | 根据行内已有账号 ID 查询该账号的策划详情 |
| 执行方式 | 同库查询方法，返回已保存的策划结果 |
| 查询范围 | 覆盖自动及人工策划、相关历史周期和批次 |

查询不触发策划、排期、内容生产或标签更新。

### 2. 输入字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 账号 ID | 是 | 行内已有的账号标识 |
| 投放开始日期 | 否 | 查询该日期及之后的策划，包含该日 |
| 投放结束日期 | 否 | 查询该日期及之前的策划，包含该日 |
| 页码 | 是 | 从第 1 页开始，按策划明细分页 |
| 每页条数 | 是 | 每页返回的策划明细数量，上限由双方确认 |

不传日期范围时查询该账号全部历史策划，并包含尚未排期的人工营销明细。传日期范围时按投放日期筛选，未排期记录不在该日期范围内。仅传一端时，仅限制对应日期边界。

调用方不需要传槽位 ID、批次 ID、策划结果版本或生产任务 ID。同一轮分页保持查询条件及每页条数不变。

### 3. 返回字段

| 字段 | 说明 |
| --- | --- |
| 查询时间（`queried_at`） | 本次查询时间 |
| 查询状态（`status`） | 查询成功／查询失败 |
| 账号 ID | 本次查询的账号 |
| 账号昵称 | 对应账号昵称 |
| 明细总数（`total_count`） | 符合查询条件的策划明细总数 |
| 当前页码（`page_no`） | 当前返回页码 |
| 每页条数（`page_size`） | 本次采用的分页大小 |
| 策划明细列表（`planning_results`） | 当前页结果，每条明细包含以下信息 |

### 4. 每条策划明细

| 字段 | 说明 |
| --- | --- |
| 批次名称（`batch_name`） | 所属策划批次名称 |
| 批次号（`batch_code`） | 所属策划批次编号，由结果返回，不作为必填查询条件 |
| 策划方式（`plan_type`） | 自动策划／人工策划 |
| 槽位类型（`slot_type`） | 普通／营销／热点 |
| 周期开始日期（`cycle_start`） | 所属周期开始日期；尚未确定时为空 |
| 周期结束日期（`cycle_end`） | 所属周期结束日期；尚未确定时为空 |
| 投放日期（`publish_date`） | 最终安排的日期；尚未排期时为空 |
| 星期（`weekday`） | 根据投放日期计算，周一至周日；未排期时为空 |
| 策划状态（`planning_status`） | 本条策划当前状态 |
| 内容状态（`content_status`） | 本条内容处理状态；未最终确定的枚举映射按文末待确认事项处理 |
| 选题信息（`topic_info`） | 普通／热点的选题详情；热点尚未定题及营销明细为空 |
| 营销内容信息（`marketing_content_info`） | 已填充营销内容的详情；非营销及尚未填充时为空 |
| 结果更新时间（`updated_at`） | 本条策划或处理状态的最后更新时间 |

选题信息包含：选题 ID、选题来源、选题标题、选题大纲、内容类型、有效开始时间、有效结束时间。

营销内容信息包含：内容 ID、内容标题、内容正文、关联产品、关联活动、审核通过时间。暂不包含图片列表。

### 5. 返回口径

- 以策划明细为单位，同一账号同一天的多条策划分别返回，不按日期覆盖。
- 合并符合范围的自动、人工及各历史批次结果，不要求调用方预先知道批次号。
- 按投放日期从新到旧返回；未排期明细单独保持稳定顺序，不为其补造日期。
- 已知账号没有策划时，查询成功、明细总数为 0、列表为空；账号不存在或查询异常时明确返回查询失败。
- 营销内容已过审，不因本次查询重新生产。内容关联及日期保存完成后可判定本次营销衔接完成，不等于已经发布。
- 查询只返回结果，选题标签及正式使用次数分别通过 OP-03、OP-02 获取。

## 九、OP-02 选题使用次数查询能力

### 1. 基本说明

| 项目 | 说明 |
| --- | --- |
| 能力提供方 | 策划侧 |
| 调用方 | 行内选题系统或运营查询功能 |
| 用途 | 查询选题在指定统计时间范围内的正式使用次数 |
| 关联标识 | 选题 ID，不将营销内容 ID 当作选题 ID |

### 2. 输入字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 选题 ID 集合 | 是 | 支持一个或多个选题，不能为空 |
| 统计开始时间 | 否 | 统计该时间及之后发生的使用事实 |
| 统计结束时间 | 否 | 统计该时间之前发生的使用事实 |

不传统计时间范围时返回累计次数；仅传一端时仅限制对应边界。这里是使用事实的统计时间，不是选题更新时间或投放日期。

### 3. 返回字段

| 字段 | 说明 |
| --- | --- |
| 查询时间（`queried_at`） | 本次查询时间 |
| 查询状态（`status`） | 查询成功／查询失败 |
| 逐条结果（`topic_results`） | 各选题的统计结果 |

每条统计结果包含：

| 字段 | 说明 |
| --- | --- |
| 选题 ID | 对应输入的选题 |
| 正式使用次数（`official_use_count`） | 该选题在统计范围内的正式使用次数，非负整数 |

### 4. 统计边界

- 同一选题用于不同槽位，分别形成有效使用事实时分别统计。
- 查询、打标测试、仅选中选题及未完成的生产不增加正式使用次数。
- 已过审营销内容只做填充及排期，不能因此重复增加内容生产使用次数。
- 内容何时形成正式使用事实，需与普通／热点的完成条件一并确认，不能在状态映射尚未确定时把“生成成功”直接等同于完整流程完成。
- 批次选题数、去重选题数与选题正式使用次数属于不同统计口径，不混用。

查询到“待打标”等状态仍属于查询成功，不把空标签解释为打标完成。查询不修改正式标签，不增加使用次数。
