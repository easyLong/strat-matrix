# 多账号智能策划运营接口定义（本次开发 V1.6）

> 本版本按当前需求澄清结果整理，作为后续接口评审和开发对接基线。

## 本版本调整

- 选题标签查询由策划系统提供，原IF-05调整为OP-05；仍适用于所有类型选题，输入仅为选题ID。

- 新增 `IF-07 策划方案生产内容`：策划系统将策划 Agent 结果异步提交给平台内容生产方。
- `OP-02` 由“发布状态回传”调整为“选题内容状态回传”，接收内容生产完成、失败、发布等状态。
- `OP-03 选题批量打标`适用于普通、营销、热点所有类型选题。
- 原 `IF-06 选题正式使用次数查询`按提供方调整为 `OP-04`，由策划系统提供查询结果。

## 接口总览

分类按接口提供方划分：IF由行内系统提供，OP由策划系统提供；调用方向不作为分类依据。

本次共10个接口：行内系统提供5个IF接口（IF-01至IF-04、IF-07）；策划系统提供5个OP接口（OP-01至OP-05）。原有接口的业务能力和主要字段均予保留；原IF-06选题正式使用次数查询已按提供方调整为OP-04；新增IF-07策划方案生产内容接口，OP-03为所有类型选题批量打标接口。

| ID | 接口能力 | 方向 | 当前用途 |

| --- | --- | --- | --- |

| IF-01 | 账号基础信息 + 账号人设 + 互动数据离线同步 | 平台账号接口 → 策划系统 | 每日夜间同步账号池、别名、认证状态、账号人设及近3个月互动数据；供AI策划、手动筛号、生命周期、账号画像及新增账号识别使用；流量趋势由策划系统计算 |

| IF-02 | 普通选题同步 | 平台选题接口 → 策划系统 | 自动策划执行前同步普通选题及热度；AI、手动选题、普通兜底和人工替换均读取本地数据 |

| IF-03 | 营销选题同步 | 平台营销选题接口 → 策划系统 | 自动策划执行前同步营销选题；用于营销槽位数量计算及账号绑定、审核有效内容选择 |

| IF-04 | 热点选题同步 | 平台热点选题接口 → 策划系统 | 目标热点槽位前一天22:00前同步热点选题，22:00读取本地数据确定具体选题 |

| IF-07 | 策划方案生产内容 | 策划系统 → 平台内容生产方 | 将策划Agent结果异步提交给内容生产方，生成对应策划内容 |

| OP-01 | 策划Agent结果查询 | 平台内容生产方 → 策划系统 | 根据账号ID查询当前可生产最新一期、已确定具体选题的当前有效策划内容；发布前需再次确认 |

| OP-02 | 选题内容状态回传 | 平台内容生产方 → 策划系统 | 回传策划内容生产状态，更新对应槽位和批次内容状态 |

| OP-03 | 选题批量打标（新增内部接口） | 行内/运营调用方 → 策划系统（选题详情数组）；策划系统 → 调用方（逐条标签结果） | 批量提交所有类型选题详情，返回每条选题的T1-T6标签结果 |

| OP-04 | 选题正式使用次数查询 | 平台选题系统 → 策划系统（查询）；策划系统 → 平台选题系统（返回） | 按topic_type + topic_ids单个/批量返回普通、营销、热点三类选题正式使用次数 |

| OP-05 | 选题标签查询 | 行内选题方 → 策划系统（查询）；策划系统 → 行内选题方（标签结果） | 策划系统提供；按选题ID查询T1-T6标签JSON，适用于所有选题 |



## 接口定义

本文件面向本次开发和运营协同，保留已确认的接口能力与主要业务字段，并补充各接口提供方。具体调用方式由后续技术设计确认。

### IF-01 账号基础信息 + 账号人设 + 互动数据离线同步接口

| 接口用途 | 每日夜间离线同步平台账号池、账号基础信息、账号人设及近3个月历史互动数据，供AI自动策划、手动筛号、生命周期判断、账号画像及新增账号识别使用。账号基础信息包含账号ID、昵称、属主UM号、属主组织、业务线、平台、地域、粉丝量和账号状态。 |

| --- | --- |

| 调用时机 | 每日夜间离线任务执行时同步；自动策划和手动策划执行时不实时调用IF-01，直接读取策划系统最近一次成功同步的数据快照。 |

| 提供方/发起方 | 平台账号系统提供账号事实及近3个月互动数据；策划系统接收并计算策划指标。 |



| 请求字段 | 字段含义 |

| --- | --- |

| 无核心业务请求字段 | 默认同步当前账号池；全量/增量、分页等技术参数由后续接口文档定义。 |



| 返回字段 | 字段含义 |

| --- | --- |

| account_id | 账号唯一标识 |

| account_name | 账号昵称 |

| um_no | 属主UM号 |

| account_status | 账号状态，表示账号是否有效及是否可参与策划 |

| organization | 属主组织 |

| account_persona | 账号人设；描述账号内容定位、身份设定和表达方向，是账号画像、向量生成及选题匹配的核心输入 |

| business_line | 业务线 |

| platform | 账号所属平台 |

| region | 账号地域；当前本地数据层兼容映射为地域/城市字段 |

| follower_count | 账号当前粉丝量 |

| interaction_data | 账号近3个月帖子级互动明细：发帖时间、帖子标题、红星数、收藏数、评论数；用于有效内容篇数、滚动互动、流量趋势、生命周期判断和账号画像。流量趋势由策划系统基于该数据计算，不作为IF-01独立字段。 |



### IF-02 普通选题同步接口

| 接口用途 | 在自动策划执行前将平台普通选题基础数据同步至策划系统，供AI候选、手动选题和人工替换使用。 |

| --- | --- |

| 调用时机 | 每次自动策划执行前完成同步；策划任务运行时直接读取策划系统本地最新同步的普通选题数据。 |

| 提供方/发起方 | 平台普通选题系统提供普通选题及热度数据；策划系统接收并维护本地选题。 |



| 请求字段 | 字段含义 |

| --- | --- |

| topic_id | 选题唯一标识 |

| title | 选题标题 |

| outline | 选题大纲 / 核心内容 |

| topic_type | 选题类型；IF-02 应为非营销普通选题 |

| content_type | 内容类型，直接继承源系统 |

| topic_heat | 选题热度；用于候选排序和普通选题兜底 |

| valid_from / valid_to | 选题有效期起止时间；为空表示对应边界不限制 |



| 返回字段 | 字段含义 |

| --- | --- |

| topic_id | 普通选题唯一标识 |

| title | 选题标题 |

| outline | 选题大纲 / 核心内容 |

| content_type | 内容类型，直接继承源系统 |

| topic_heat | 普通选题当前可排序热度值；用于普通匹配无结果及热点无合法选题时选择“普通最热”兜底，具体源字段映射由接口文档确定 |

| status | 选题当前是否有效可用 |

| valid_from / valid_to | 选题有效期起止时间 |



### IF-03 营销选题同步接口

| 接口用途 | 在自动策划执行前将平台营销选题同步至策划系统，供营销账号的营销槽位使用。 |

| --- | --- |

| 调用时机 | 每次自动策划执行前完成同步；自动策划运行时读取策划系统本地最新同步的营销选题数据。 |

| 提供方/发起方 | 平台营销选题系统提供选题、绑定账号及审核事实；策划系统接收并判断可用性。 |



| 请求字段 | 字段含义 |

| --- | --- |

| topic_id | 营销选题唯一标识 |

| account_id | 绑定的营销账号 ID |

| title | 选题标题 |

| outline | 选题大纲 / 核心内容 |

| approval_status | 审核状态：待审核、审核通过或审核驳回；具体枚举由平台系统确认 |

| valid_from / valid_to | 选题有效期起止时间；为空表示对应边界不限制 |

| topic_heat | 营销选题热度；用于营销选题排序或运营筛选 |



| 返回字段 | 字段含义 |

| --- | --- |

| topic_id | 营销选题唯一标识；策划侧统一按topic_id识别选题 |

| account_id | 该营销选题绑定的营销账号ID |

| title | 营销选题标题 |

| outline | 营销选题大纲 / 核心内容 |

| content_type | 内容类型，与普通选题一致，直接继承源系统 |

| status | 营销选题当前是否有效可用 |

| audit_status | 营销选题审核状态 |

| approved_at | 审核通过时间；多条可用营销选题按该时间升序逐条优先使用 |



### IF-04 热点选题同步接口

| 接口用途 | 将平台热点选题同步至策划系统，供已提前规划的热点槽位在T-1日22:00确定具体热点选题。 |

| --- | --- |

| 调用时机 | 目标热点槽位前一天22:00前完成同步；22:00任务直接读取策划系统本地最新有效热点数据。 |

| 提供方/发起方 | 平台热点选题系统提供热点内容及有效状态；策划系统接收并匹配热点槽位。 |



| 请求字段 | 字段含义 |

| --- | --- |

| topic_id | 热点选题唯一标识 |

| title | 选题标题 |

| outline | 选题大纲 / 核心内容 |

| content_type | 内容类型，直接继承源系统 |

| status | 选题当前是否有效可用 |

| valid_from / valid_to | 选题有效期起止时间；为空表示对应边界不限制 |

| topic_heat | 热点选题热度；用于热点候选排序或运营筛选 |



| 返回字段 | 字段含义 |

| --- | --- |

| topic_id | 热点选题唯一标识；策划侧统一按topic_id识别选题 |

| title | 热点选题标题 |

| outline | 热点选题大纲 / 核心内容 |

| content_type | 内容类型，与普通选题一致，直接继承源系统 |

| status | 热点选题当前是否有效可用 |

| topic_heat | 热点选题热度 |



### IF-07 策划方案生产内容接口

| 接口用途 | 策划系统将已完成匹配的策划Agent结果提交给平台内容生产方，由内容生产方异步生产对应内容。 |

| --- | --- |

| 调用时机 | 策划结果确认后，或运营在手动策划任务中点击“去生产内容”后调用；接口只负责提交生产任务，不同步等待内容结果。 |

| 提供方/发起方 | 策划系统发起调用；平台内容生产方接收策划Agent结果并异步执行内容生产。 |



| 请求字段 | 字段含义 |

| --- | --- |

| planning_agent_result | 策划Agent结果对象；作为内容生产方生成内容的完整输入。 |

| planning_agent_result.planning_result_id | 策划结果唯一标识。 |

| planning_agent_result.account_id | 账号唯一标识。 |

| planning_agent_result.slot_id | 策划槽位唯一标识。 |

| planning_agent_result.version | 当前策划结果版本。 |

| planning_agent_result.publish_date | 计划投放日期。 |

| planning_agent_result.topic_id | 选题唯一标识。 |

| planning_agent_result.topic_type | 选题类型：普通 / 营销 / 热点。 |

| planning_agent_result.title | 选题标题。 |

| planning_agent_result.outline | 选题大纲。 |

| planning_agent_result.content_type | 内容类型。 |

| planning_agent_result.tags | 策划Agent输出的标签结果。 |

| planning_agent_result.content_agent_input | 提供给内容生产方的结构化生产参数。 |



| 返回字段 | 字段含义 |

| --- | --- |

| accepted | 是否已受理生产任务。 |

| production_task_id | 内容生产任务唯一标识。 |

| status | 当前受理状态：已受理 / 已存在。 |

| 说明 | 内容生产为异步流程，最终生产结果和内容状态由OP-02回传。 |



### OP-01 策划Agent结果查询接口

| 接口用途 | 供内容生产方根据账号ID查询该账号当前“可生产最新一期”的当前有效策划内容。 |

| --- | --- |

| 调用时机 | 内容生产方获取生产任务时主动调用，并在正式发布前再次调用确认最新结果；查询行为不改变发布状态，也不锁定人工替换。 |

| 提供方/发起方 | 平台内容生产方发起查询；策划系统提供当前可生产的策划结果。 |



| 请求字段 | 字段含义 |

| --- | --- |

| account_id | 需要查询最新一期策划内容的账号唯一标识 |



| 返回字段 | 字段含义 |

| --- | --- |

| account_id | 当前账号ID |

| planning_cycle | 本次返回结果所属策划周期。“可生产最新一期”定义：优先返回当前自然周仍存在的未发布且已确定选题结果；当前周无此类结果时，再返回最近未来周期。 |

| planning_contents | 当前周期中已确定具体选题、当前有效且可进入内容生产的结果列表；热点“待热点触发/待确定选题”槽位不返回。每条至少包含planning_result_id、publish_date、topic_id、topic_type（普通/营销/热点）、title、outline、content_type。手动追加结果如属于该周期且未发布，同样纳入。 |



### OP-02 选题内容状态回传接口

| 接口用途 | 由内容生产方回传策划内容的生产状态，用于更新策划结果、批次内容状态及生产任务进度。 |

| --- | --- |

| 调用时机 | 内容生产状态发生变化时调用；内容生产方在任务完成或生产失败后回传，支持异步重试和重复事件幂等处理。 |

| 提供方/发起方 | 平台内容生产方回传内容生产状态；策划系统校验任务版本并更新本地状态。 |



| 请求字段 | 字段含义 |

| --- | --- |

| event_id | 状态事件唯一标识，用于重复回传幂等处理。 |

| production_task_id | IF-07返回的内容生产任务 ID。 |

| slot_id | 策划槽位唯一标识。 |

| version | 当前策划结果版本。 |

| status | 内容生产状态：已生成 / 生成失败 / 已发布。 |

| content_id | 生产内容唯一标识；已生成或已发布时必填。 |

| occurred_at | 状态发生时间，必须带时区。 |

| failure_reason | 生产失败原因；状态为生成失败时提供。 |



| 返回字段 | 字段含义 |

| --- | --- |

| accepted | 是否接受本次状态回传。 |

| applied | 是否已应用到当前策划结果。 |

| reason | 处理结果：applied / duplicate_event / old_version / state_already_advanced / content_not_ready。 |



### OP-03 选题批量打标接口（新增内部接口）

| 接口用途 | 供行内/运营调用方批量提交所有类型选题详情；策划系统完成标签识别后，返回每个选题的具体标签。 |

| --- | --- |

| 提供方/发起方 | 行内/运营调用方提交选题详情数组；策划系统提供批量识别并返回逐条T1-T6标签，内部识别组件由策划系统调用。 |

| 调用时机 | 一批选题准备打标时调用；返回结果按topic_id与输入选题对应。 |



| 请求字段 | 字段含义 |

| --- | --- |

| topic_items | 批量待打标的选题详情数组，支持普通、营销和热点选题；每个数组元素对应一条选题。 |

| topic_items[].topic_id | 选题唯一标识。 |

| topic_items[].title | 选题标题。 |

| topic_items[].outline | 选题大纲 / 核心内容。 |

| topic_items[].content_type | 内容类型。 |

| topic_items[].topic_heat | 选题热度。 |

| topic_items[].status | 选题当前是否有效可用。 |



| 返回字段 | 字段含义 |

| --- | --- |

| topic_results | 批量选题打标结果数组；每个结果对应一条输入选题。 |

| topic_results[].topic_id | 本条打标结果对应的选题唯一标识。 |

| topic_results[].labels | 该选题的T1-T6标签集合。 |

| topic_results[].labels.t1 | 该选题的T1标签。 |

| topic_results[].labels.t2 | 该选题的T2标签。 |

| topic_results[].labels.t3 | 该选题的T3标签。 |

| topic_results[].labels.t4 | 该选题的T4标签。 |

| topic_results[].labels.t5 | 该选题的T5标签。 |

| topic_results[].labels.t6 | 该选题的T6标签。 |

### OP-04 选题正式使用次数查询接口

| 接口用途 | 供平台选题系统查询选题当前正式使用次数；支持普通选题、营销选题、热点选题三种类型。单次批量查询按一个topic_type执行。 |

| --- | --- |

| 调用时机 | 平台选题系统需要展示、筛选或核对选题正式使用次数时调用。 |

| 提供方/发起方 | 平台选题系统发起查询；策划系统提供次数查询接口，返回从独立业务统计来源同步的计数。 |



| 请求字段 | 字段含义 |

| --- | --- |

| topic_type | 本次查询选题类型：普通 / 营销 / 热点；用于区分三类选题ID命名空间 |

| topic_ids | 该topic_type下需要查询的选题ID集合；支持单个或批量查询 |



| 返回字段 | 字段含义 |

| --- | --- |

| topic_type | 选题类型：普通 / 营销 / 热点 |

| topic_id | 选题唯一标识 |

| official_use_count | 该选题当前正式使用次数；由策划系统独立业务逻辑维护，OP-04仅提供查询 |

### OP-05 选题标签查询接口

| 接口用途 | 供平台选题方按选题ID查询策划系统已识别的T1-T6标签结果，适用于普通、营销和热点选题。 |

| --- | --- |

| 调用时机 | 平台选题方需要展示或使用选题标签时主动查询；接口只查询结果，不触发标签计算。 |

| 提供方/发起方 | 策划系统提供选题标签查询接口；行内选题方发起调用，策划系统返回该选题已识别的标签。 |
