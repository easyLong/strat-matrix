# IF-05 / IF-06 本地对接契约

依据《多账号智能策划_PRD_V1.0.docx》第 8.2.5～8.2.6 节。客户尚未提供地址和鉴权协议，本版使用项目服务上的 HTTP JSON 接口和 `X-Integration-Token` 请求头。令牌由项目根目录 `.env` 中的 `INTEGRATION_TOKEN` 配置；没有令牌时接口返回 503。

## IF-05 按账号查询可生产结果

`GET /api/integrations/accounts/{account_id}/current-plan`

返回格式：

```json
{
  "account_id": "ACCOUNT-001",
  "planning_cycle": {"start": "2026-10-12", "end": "2026-10-18"},
  "planning_contents": [
    {
      "planning_result_id": 123,
      "slot_id": "SLOT-123",
      "result_version": 1,
      "publish_date": "2026-10-12",
      "topic_id": "TOPIC-001",
      "topic_type": "普通",
      "title": "选题标题",
      "outline": "内容大纲",
      "content_type": "图文",
      "publish_status": "未发布"
    }
  ]
}
```

按北京时间的自然周选期：本周有未发布且已确定选题的结果时返回本周，否则取最近的未来周期。无结果时 `planning_cycle` 为 `null`，列表为空。当前有效的手动追加结果也纳入。热点待定空槽、已发布结果、`DEMO-` 批次不返回。查询不修改状态，也不锁定人工替换；正式发布前应再次查询。`planning_result_id` 和 `result_version` 用于后续回传的一致性校验。

## IF-06 发布状态回传

`POST /api/integrations/publication-status`

```json
{
  "event_id": "PUB-20261012-001",
  "planning_result_id": 123,
  "result_version": 1,
  "topic_id": "TOPIC-001",
  "topic_type": "普通",
  "publish_status": "已发布",
  "occurred_at": "2026-10-12T09:00:00+08:00",
  "content_id": "CONTENT-001"
}
```

`event_id` 用于重试去重，`result_version` 来自最近一次 IF-05 查询。`topic_type` 仅接受“普通 / 营销 / 热点”，`publish_status` 仅接受“未发布 / 已发布”；`occurred_at` 必须带时区，`content_id` 可省略。匹配当前有效版本、选题 ID 和选题类型后，返回 `current_publish_status`。“已发布”会更新策划结果和槽位发布状态，关闭人工替换；“未发布”不会回退已经发布的结果。

不一致的回传返回 HTTP 409、`reason=result_mismatch`，保存在 `godp_publication_receipt` 供排查，不会更改发布状态。同一 `event_id`、相同请求重传不会重复生效；同一 `event_id` 对应不同请求返回 409。`/api/integrations/content-status` 是既有内容生成进度接口，与本接口分开。

部署更新后先运行 `cd backend && python3 -m app.init_db`，创建带中文表注释与字段注释的回传记录表。
