# 最新版前端 UI 离线评审文件

交付文件：`review-export/多账号智能策划_最新版前端UI_离线评审.html`。

直接使用当前 `frontend/src` 的 Vue 页面和样式构建，不额外绘制一套页面。MiSans 字体、CSS、JavaScript、接口数据快照均内嵌，发送这个 HTML 文件即可使用 Edge / Chrome 双击离线评审。

## 版本核对

本次核对的 GitHub 最新 main 为 `33917a2`，本地 HEAD 为 `c969df3`。两者的 frontend 目录内容一致，其 Git tree 均为 `2df1629f8e07bbe49178f23330cc39d1456ada21`。远端新增的三个提交属于后端开发。

HTML 内的 `window.__STRAT_MATRIX_REVIEW_BUILD__` 记录构建提交、前端目录树、构建时间与实际 Vite 资源名称。

## 原型范围

- UI、字段、布局、页面入口与交互均来自现有前端源码。
- 数据取自本地运行服务的导出时快照。本次为68个账号、8个选题、21个批次。
- 账号历史直接保存 `/api/items?account=...&limit=5000` 的完整响应及原始排序，确保账号生命周期、周历及详情与运行页面一致。
- 配置编辑、历史恢复、标签操作、人工策划提交、查询与替换选题由本地模拟接口支持，不改动真实数据库。
- 当前源码中的人工策划流程为「创建策划 → 选择账号 → 选择选题 → 确认策划」，离线文件保持相同流程。
- 现有源码中的内容生产与内容流水仍为预留入口，离线版保持现有实现，不额外构造内容系统页面。
- 离线修改只在当前页面会话内生效；重新打开恢复导出时快照。
- 两份此前交付的同名 HTML 也会更新为相同内容，避免旧链接打开错误版本。

## 重新生成

先启动本地后端（默认端口6930），然后在仓库根目录运行：

```bash
node scripts/build-review-prototype.mjs
```

脚本自动执行前端构建、读取后端快照、嵌入字体与资源并生成单文件。其他API地址通过 `REVIEW_API_BASE` 指定。
